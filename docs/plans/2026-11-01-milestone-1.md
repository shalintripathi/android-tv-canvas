# Canvas Milestone 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship Canvas milestone 1: a fast Android TV home screen and a photo-frame screensaver fed from the owner's phone over Wi-Fi, with tooling to install and undo it on a TV.

**Architecture:** Two Gradle modules. `core` is plain Kotlin on the JVM: slide planning, captions, the HTTP server, pairing, the photo index and the dock model, all unit-tested without Android. `app` is the Android TV app built from framework Views: the home screen, the `DreamService`, the photo library, and the phone page that serves `core`'s HTTP server. Python tooling in `tools/` drives the TV over ADB.

**Tech Stack:** Kotlin 2.1.0, Gradle 8.11.1 (wrapper), Android Gradle Plugin 8.7.3, compileSdk/targetSdk 35, minSdk 24, ZXing core 3.5.3, JUnit 4.13.2, org.json 20240303 (tests only; Android ships org.json), GitHub Actions, Python 3 with `adb-shell`.

**Spec:** `docs/specs/2026-11-01-canvas-design.md`

## Global Constraints

- Package and applicationId `io.github.shalintripathi.canvas`; app label `Canvas`.
- minSdk 24, targetSdk 35, compileSdk 35. Anything above API 24 sits behind a `Build.VERSION.SDK_INT` check.
- No native code and no libraries that bundle `.so` files. Milestone 1 runtime dependencies: Kotlin stdlib, ZXing core. Nothing else.
- Framework Views only: no Jetpack Compose, no AndroidX.
- `core` must not import any `android.*` class.
- The phone page server listens on port **8765**, takes uploads up to **40 MB**, and serves one static page from `app/src/main/assets/web/index.html`. No CDN, no framework.
- Stored photos: long side **1920 px**, JPEG quality **88**; thumbnails: long side **320 px**, quality **80**.
- Pairing codes expire after **10 minutes**; **5** wrong PINs void a code; sessions are random 256-bit values stored only as SHA-256 hashes.
- Screensaver defaults: **30 s** per photo (range 10–300), **1.5 s** crossfade, Ken Burns scale 1.0 to **1.08**, overlay shifts up to **24 dp** every **5 minutes**.
- Home wallpaper changes every **10 minutes**.
- Dock holds at most **7** apps.
- This Mac has no JDK or Android SDK: every compile and test runs in GitHub Actions on branch `milestone-1`. Use `tools/fetch-ci-apk.sh` to get the APK and `tools/canvas install` to put it on the TV.
- Commit author is the owner's git identity (`Shivakant Tripathi <shalintripathi@users.noreply.github.com>`). Commit messages have no attribution trailers.

## How to run the test cycle in this repo

There is no local JVM. A "run the tests" step means:

```bash
git push -u origin milestone-1
tools/fetch-ci-apk.sh          # waits for the CI run of the pushed commit, prints test results, downloads the APK to build/ci/
```

`fetch-ci-apk.sh` exits non-zero when the run fails and prints the failing step's log tail. TDD's "watch it fail" step is folded into the same push when a red run would cost a full CI cycle for no information; the test file is still written first.

```kotlin file=core/src/test/kotlin/io/github/shalintripathi/canvas/core/ImageMathTest.kt
package io.github.shalintripathi.canvas.core

import org.junit.Assert.assertEquals
import org.junit.Test

class ImageMathTest {
    @Test
    fun sampleToFillKeepsBothSidesAtLeastTheTarget() {
        assertEquals(2, ImageMath.sampleToFill(4000, 3000, 1920, 1080))
        assertEquals(1, ImageMath.sampleToFill(1920, 1080, 1920, 1080))
        assertEquals(4, ImageMath.sampleToFill(8000, 6000, 1920, 1080))
        // A portrait filling a landscape screen is limited by its width.
        assertEquals(1, ImageMath.sampleToFill(3000, 4000, 1920, 1080))
    }

    @Test
    fun sampleToFillIgnoresMissingTargets() {
        assertEquals(1, ImageMath.sampleToFill(4000, 3000, 0, 0))
    }

    @Test
    fun sampleForLongSideKeepsTheLongSideAtLeastMax() {
        assertEquals(2, ImageMath.sampleForLongSide(4032, 3024, 1920))
        assertEquals(4, ImageMath.sampleForLongSide(3024, 8064, 1920))
        assertEquals(1, ImageMath.sampleForLongSide(1200, 800, 1920))
    }

    @Test
    fun fitLongSideShrinksButNeverEnlarges() {
        assertEquals(1920 to 1440, ImageMath.fitLongSide(4032, 3024, 1920))
        assertEquals(1080 to 1920, ImageMath.fitLongSide(2160, 3840, 1920))
        assertEquals(800 to 600, ImageMath.fitLongSide(800, 600, 1920))
    }
```

```kotlin file=core/src/main/kotlin/io/github/shalintripathi/canvas/core/ImageMath.kt
package io.github.shalintripathi.canvas.core

/** Decode-size maths shared by the importer and the slideshow. */
object ImageMath {
    /** Largest power-of-two sample size that keeps both sides at least the requested size (for centre-crop). */
    fun sampleToFill(width: Int, height: Int, reqWidth: Int, reqHeight: Int): Int {
        if (reqWidth <= 0 || reqHeight <= 0) return 1
        var sample = 1
        while (width / (sample * 2) >= reqWidth && height / (sample * 2) >= reqHeight) sample *= 2
        return sample
    }

    /** Largest power-of-two sample size that keeps the long side at least [maxSide]. */
    fun sampleForLongSide(width: Int, height: Int, maxSide: Int): Int {
        val long = maxOf(width, height)
        var sample = 1
        while (long / (sample * 2) >= maxSide) sample *= 2
        return sample
    }

    /** Size after shrinking so the long side is at most [maxSide]. Never enlarges. */
    fun fitLongSide(width: Int, height: Int, maxSide: Int): Pair<Int, Int> {
        val long = maxOf(width, height)
        if (long <= maxSide) return width to height
        val w = (width.toLong() * maxSide / long).toInt().coerceAtLeast(1)
        val h = (height.toLong() * maxSide / long).toInt().coerceAtLeast(1)
        return w to h
    }
}
```

```bash file=tools/fetch-ci-apk.sh
#!/usr/bin/env bash
# Wait for the CI run of the current commit, show the result, and download its debug APK to build/ci/.
#   tools/fetch-ci-apk.sh            the commit at HEAD
#   tools/fetch-ci-apk.sh <sha>      another pushed commit
set -euo pipefail
cd "$(dirname "$0")/.."
SHA="${1:-$(git rev-parse HEAD)}"

echo "Waiting for CI on ${SHA:0:7}…"
RUN=""
for _ in $(seq 1 60); do
  RUN=$(gh run list --commit "$SHA" --workflow CI --limit 1 --json databaseId -q '.[0].databaseId' 2>/dev/null || true)
  [ -n "$RUN" ] && break
  sleep 5
done
[ -n "$RUN" ] || { echo "No CI run found for $SHA. Did you push?"; exit 1; }

if ! gh run watch "$RUN" --exit-status --interval 15 >/dev/null; then
  echo "CI failed: $(gh run view "$RUN" --json url -q .url)"
  gh run view "$RUN" --log-failed | tail -80
  exit 1
fi

rm -rf build/ci && mkdir -p build/ci
gh run download "$RUN" -n canvas-debug-apk -D build/ci
echo "CI passed. APK: build/ci/app-debug.apk ($(wc -c < build/ci/app-debug.apk) bytes)"
```

```python file=tools/canvas.py
"""Canvas TV tool: talk to an Android TV over Wi-Fi ADB.

    tools/canvas find                      scan the Wi-Fi, remember the first TV with ADB open
    tools/canvas probe                     model and Android version
    tools/canvas sh '<command>'            run a shell command on the TV
    tools/canvas shot out.png              screenshot
    tools/canvas install [apk] [--app-only]
                                           install Canvas; without --app-only also make it the
                                           home screen and screensaver (backs up first)
    tools/canvas restore [--uninstall]     undo `install` from the backup
    tools/canvas debloat <list>            disable the packages in a list (reversible)
    tools/canvas undebloat <list>          re-enable them

The TV address comes from $TV_HOST or tools/.tv_host (written by `find`).
"""
import datetime
import errno
import hashlib
import json
import os
import platform
import socket
import subprocess
import sys
import threading
import time
from concurrent.futures import ThreadPoolExecutor

from adb_shell.adb_device import AdbDeviceTcp
from adb_shell.auth.keygen import keygen
from adb_shell.auth.sign_pythonrsa import PythonRSASigner

HERE = os.path.dirname(os.path.abspath(__file__))
ROOT = os.path.dirname(HERE)
HOST_FILE = os.path.join(HERE, ".tv_host")
KEY = os.path.join(HERE, "adbkey", "adbkey")
BACKUPS = os.path.join(HERE, "backups")
SHOTS = os.path.join(ROOT, "shots")

PKG = "io.github.shalintripathi.canvas"
HOME = PKG + "/.home.HomeActivity"
DREAM = PKG + "/.frame.FrameDreamService"
STOCK_HOMES = ["com.google.android.apps.tv.launcherx", "com.google.android.tungsten.setupwraith"]
SECURE_KEYS = ["screensaver_components", "screensaver_enabled", "screensaver_activate_on_sleep", "sleep_timeout"]
SYSTEM_KEYS = ["screen_off_timeout"]
ADB_PORT = 5555


# ---------------------------------------------------------------- connection

class NcRelay:
    """macOS blocks LAN access for non-Apple binaries. Apple's nc is allowed, so pipe ADB through it."""

    def __init__(self, host, port):
        self.host, self.port = host, port
        self.server = socket.socket()
        self.server.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
        self.server.bind(("127.0.0.1", 0))
        self.server.listen(4)
        self.local_port = self.server.getsockname()[1]
        threading.Thread(target=self._accept, daemon=True).start()

    def _accept(self):
        while True:
            try:
                client, _ = self.server.accept()
            except OSError:
                return
            proc = subprocess.Popen(["/usr/bin/nc", self.host, str(self.port)],
                                    stdin=subprocess.PIPE, stdout=subprocess.PIPE, bufsize=0)
            threading.Thread(target=self._to_tv, args=(client, proc), daemon=True).start()
            threading.Thread(target=self._from_tv, args=(client, proc), daemon=True).start()

    @staticmethod
    def _to_tv(client, proc):
        try:
            while True:
                data = client.recv(65536)
                if not data:
                    break
                proc.stdin.write(data)
        except OSError:
            pass
        finally:
            try:
                proc.stdin.close()
            except OSError:
                pass

    @staticmethod
    def _from_tv(client, proc):
        try:
            while True:
                data = os.read(proc.stdout.fileno(), 65536)
                if not data:
                    break
                client.sendall(data)
        except OSError:
            pass
        finally:
            client.close()
            proc.kill()


def tv_host():
    host = os.environ.get("TV_HOST")
    if not host and os.path.exists(HOST_FILE):
        host = open(HOST_FILE).read().strip()
    if not host:
        sys.exit("Don't know your TV's address. Run `tools/canvas find`, or set TV_HOST=192.168.x.y")
    return host


def signer():
    os.makedirs(os.path.dirname(KEY), exist_ok=True)
    if not os.path.exists(KEY):
        keygen(KEY)
    with open(KEY) as private, open(KEY + ".pub") as public:
        return PythonRSASigner(public.read(), private.read())


def _connect(host, port):
    dev = AdbDeviceTcp(host, port, default_transport_timeout_s=60.0)
    dev.connect(rsa_keys=[signer()], auth_timeout_s=120)
    return dev


def connect():
    host, port = tv_host(), int(os.environ.get("TV_PORT", ADB_PORT))
    print(f"Connecting to {host}… (accept \"Allow USB debugging?\" on the TV if it asks)", file=sys.stderr)
    try:
        return _connect(host, port)
    except OSError as e:
        if platform.system() != "Darwin" or e.errno not in (errno.EHOSTUNREACH, errno.ENETUNREACH):
            raise
    relay = NcRelay(host, port)
    return _connect("127.0.0.1", relay.local_port)


def sh(dev, command):
    return dev.shell(command, read_timeout_s=120).strip()


def run(dev, command):
    """One command per shell call: chained `pm` commands can silently stop after the first."""
    print(f"$ {command}")
    out = sh(dev, command)
    if out:
        print(out)
    return out


def push(dev, local, remote):
    dev.push(local, remote, read_timeout_s=300)
    remote_md5 = sh(dev, f"md5sum {remote}").split()[0]
    with open(local, "rb") as f:
        local_md5 = hashlib.md5(f.read()).hexdigest()
    if remote_md5 != local_md5:
        sys.exit(f"Upload corrupted: md5 {remote_md5} != {local_md5}")


# ---------------------------------------------------------------- commands

def cmd_find():
    me = local_ip()
    net = me.rsplit(".", 1)[0]
    print(f"Scanning {net}.0/24 from {me}…")
    names = mdns_names()
    if names:
        print("Android TVs announcing themselves: " + ", ".join(names))
    with ThreadPoolExecutor(64) as pool:
        hits = [ip for ip in pool.map(lambda i: f"{net}.{i}" if port_open(f"{net}.{i}", ADB_PORT) else None,
                                      range(1, 255)) if ip]
    if not hits:
        sys.exit("No TV with ADB open. On the TV: Developer options → USB debugging, then run this again.")
    print("ADB open on: " + ", ".join(hits))
    with open(HOST_FILE, "w") as f:
        f.write(hits[0])
    print(f"Saved {hits[0]}. Next: tools/canvas probe")


def local_ip():
    s = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)
    try:
        s.connect(("8.8.8.8", 80))
        return s.getsockname()[0]
    finally:
        s.close()


def port_open(ip, port):
    args = ["nc", "-z", "-w", "1"] + (["-G", "1"] if platform.system() == "Darwin" else []) + [ip, str(port)]
    return subprocess.run(args, capture_output=True).returncode == 0


def mdns_names():
    """Names of Android TVs on the network (macOS only; dns-sd never exits on its own)."""
    if platform.system() != "Darwin":
        return []
    try:
        out = subprocess.run(["dns-sd", "-B", "_androidtvremote2._tcp", "local."],
                             capture_output=True, text=True, timeout=3).stdout
    except subprocess.TimeoutExpired as e:
        out = e.stdout.decode() if isinstance(e.stdout, bytes) else (e.stdout or "")
    return sorted({" ".join(line.split()[6:]) for line in out.splitlines() if " Add " in line})


def cmd_probe():
    dev = connect()
    for prop in ("ro.product.manufacturer", "ro.product.model", "ro.build.version.release",
                 "ro.build.version.sdk", "ro.build.display.id"):
        print(f"{prop} = {sh(dev, f'getprop {prop}')}")
    print("home = " + current_home(dev))
    print("screensaver = " + sh(dev, "settings get secure screensaver_components"))


def cmd_shot(path):
    dev = connect()
    sh(dev, "screencap -p /sdcard/_canvas_shot.png")
    dev.pull("/sdcard/_canvas_shot.png", path)
    sh(dev, "rm /sdcard/_canvas_shot.png")
    print(f"saved {path}")


def current_home(dev):
    out = sh(dev, "cmd package resolve-activity --brief -a android.intent.action.MAIN "
                  "-c android.intent.category.HOME")
    return out.splitlines()[-1].strip() if out else ""


def installed(dev, pkg):
    return f"package:{pkg}" in sh(dev, f"pm list packages {pkg}").split()


def enabled(dev, pkg):
    return f"package:{pkg}" not in sh(dev, f"pm list packages -d {pkg}").split()


def backup_path(dev):
    return os.path.join(BACKUPS, sh(dev, "settings get secure android_id") + ".json")


def take_backup(dev):
    """Back up once per TV. Re-installs keep the first backup so `restore` returns to the stock setup."""
    path = backup_path(dev)
    if os.path.exists(path):
        print(f"Keeping the existing backup {os.path.relpath(path, ROOT)}")
        return path
    data = {
        "taken": datetime.datetime.now().isoformat(timespec="seconds"),
        "model": sh(dev, "getprop ro.product.model"),
        "home": current_home(dev),
        "secure": {k: sh(dev, f"settings get secure {k}") for k in SECURE_KEYS},
        "system": {k: sh(dev, f"settings get system {k}") for k in SYSTEM_KEYS},
        "disabled_by_canvas": [],
    }
    os.makedirs(BACKUPS, exist_ok=True)
    with open(path, "w") as f:
        json.dump(data, f, indent=2)
    print(f"Backed up the TV's settings to {os.path.relpath(path, ROOT)}")
    return path


def default_apk():
    for candidate in ("app/build/outputs/apk/release/app-release.apk",
                      "app/build/outputs/apk/debug/app-debug.apk", "build/ci/app-debug.apk"):
        path = os.path.join(ROOT, candidate)
        if os.path.exists(path):
            return path
    sys.exit("No APK found. Run tools/fetch-ci-apk.sh or pass the APK path.")


def cmd_install(args):
    apk = next((a for a in args if not a.startswith("--")), None) or default_apk()
    app_only = "--app-only" in args
    dev = connect()
    path = take_backup(dev)
    print(f"Uploading {os.path.relpath(apk, ROOT)}…")
    push(dev, apk, "/data/local/tmp/canvas.apk")
    out = run(dev, "pm install -r -g /data/local/tmp/canvas.apk")
    sh(dev, "rm -f /data/local/tmp/canvas.apk")
    if "Success" not in out:
        hint = (f"\nThe installed copy was signed with a different key. Remove it first:"
                f" tools/canvas sh pm uninstall {PKG}") if "UPDATE_INCOMPATIBLE" in out else ""
        sys.exit("Install failed." + hint)
    run(dev, f"pm grant {PKG} android.permission.WRITE_SECURE_SETTINGS")
    run(dev, f"appops set {PKG} WRITE_SETTINGS allow")
    if app_only:
        print("Installed (app only).")
        return

    with open(path) as f:
        backup = json.load(f)
    run(dev, f"cmd package set-home-activity --user 0 {HOME}")
    for pkg in STOCK_HOMES:
        if installed(dev, pkg) and enabled(dev, pkg):
            run(dev, f"pm disable-user --user 0 {pkg}")
            if pkg not in backup["disabled_by_canvas"]:
                backup["disabled_by_canvas"].append(pkg)
    with open(path, "w") as f:
        json.dump(backup, f, indent=2)
    run(dev, f"cmd package set-home-activity --user 0 {HOME}")
    run(dev, f"settings put secure screensaver_components {DREAM}")
    run(dev, "settings put secure screensaver_enabled 1")
    run(dev, "settings put secure screensaver_activate_on_sleep 1")
    # A stale home task from the old launcher can open Canvas behind the current app.
    run(dev, "am force-stop com.android.tv.settings")
    run(dev, "input keyevent KEYCODE_HOME")
    time.sleep(3)
    dev.close()
    os.makedirs(SHOTS, exist_ok=True)
    cmd_shot(os.path.join(SHOTS, "install-" + datetime.datetime.now().strftime("%Y%m%d-%H%M%S") + ".png"))
    print("Installed. Press Home on the remote.")


def cmd_restore(args):
    dev = connect()
    path = backup_path(dev)
    if not os.path.exists(path):
        sys.exit("No backup for this TV in tools/backups/.")
    with open(path) as f:
        backup = json.load(f)
    for pkg in backup["disabled_by_canvas"]:
        run(dev, f"pm enable {pkg}")
    for table, values in (("secure", backup["secure"]), ("system", backup["system"])):
        for key, value in values.items():
            run(dev, f"settings delete {table} {key}" if value in ("", "null")
                else f"settings put {table} {key} {value}")
    home = backup.get("home", "")
    if "/" in home and not home.startswith(PKG):
        run(dev, f"cmd package set-home-activity --user 0 {home}")
    if "--uninstall" in args:
        run(dev, f"pm uninstall {PKG}")
    run(dev, "input keyevent KEYCODE_HOME")
    print("Restored the TV's previous home screen and screensaver.")


def read_list(path):
    with open(path) as f:
        return [line.split("#", 1)[0].strip() for line in f if line.split("#", 1)[0].strip()]


def cmd_debloat(path, enable=False):
    dev = connect()
    for pkg in read_list(path):
        run(dev, f"pm enable {pkg}" if enable else f"pm disable-user --user 0 {pkg}")


def main():
    args = sys.argv[1:]
    command = args[0] if args else "help"
    if command == "find":
        cmd_find()
    elif command == "probe":
        cmd_probe()
    elif command == "sh" and len(args) > 1:
        print(sh(connect(), " ".join(args[1:])))
    elif command == "shot" and len(args) > 1:
        cmd_shot(args[1])
    elif command == "install":
        cmd_install(args[1:])
    elif command == "restore":
        cmd_restore(args[1:])
    elif command == "debloat" and len(args) > 1:
        cmd_debloat(args[1])
    elif command == "undebloat" and len(args) > 1:
        cmd_debloat(args[1], enable=True)
    else:
        print(__doc__)


if __name__ == "__main__":
    main()
```

```kotlin file=core/src/test/kotlin/io/github/shalintripathi/canvas/core/SlidePlannerTest.kt
    }

    @Test
    fun favouritesShowTwicePerRound() {
        val planner = SlidePlanner(Random(3))
        planner.setPhotos(listOf(landscape("a", favorite = true), landscape("b"), landscape("c")))
        val round = (1..4).map { (planner.next() as Slide.Single).photo.id }
        assertEquals(2, round.count { it == "a" })
        assertEquals(1, round.count { it == "b" })
        assertEquals(1, round.count { it == "c" })
        for (i in 1 until round.size) assertTrue("no back-to-back repeats: $round", round[i] != round[i - 1])
    }

    fun twoPortraitsShareTheScreen() {
        val planner = SlidePlanner(Random(5))
        planner.setPhotos(listOf(portrait("p1"), portrait("p2"), landscape("l1")))
        val slides = listOf(planner.next()!!, planner.next()!!)
        val duo = slides.filterIsInstance<Slide.Duo>().single()
        assertEquals(setOf("p1", "p2"), duo.photos.map { it.id }.toSet())
        assertEquals("l1", slides.filterIsInstance<Slide.Single>().single().photo.id)
    }

    @Test
    fun aLonePortraitShowsOnItsOwn() {
        val planner = SlidePlanner(Random(2))
        planner.setPhotos(listOf(portrait("p1")))
        assertEquals("p1", (planner.next() as Slide.Single).photo.id)
    }

    @Test
    fun previousAndNextWalkTheHistory() {
        val planner = SlidePlanner(Random(9))
        planner.setPhotos((1..5).map { landscape("p$it") })
        val a = planner.next()
        val b = planner.next()
        val c = planner.next()
```

```kotlin file=core/src/main/kotlin/io/github/shalintripathi/canvas/core/SlidePlanner.kt
package io.github.shalintripathi.canvas.core

import kotlin.random.Random

/** A photo as the slideshow sees it. [id] is a library id or "builtin:<asset name>". */
data class PhotoRef(val id: String, val portrait: Boolean, val favorite: Boolean = false)

/** What is on screen at once: one photo, or two portraits side by side. */
sealed class Slide {
    abstract val photos: List<PhotoRef>

    data class Single(val photo: PhotoRef) : Slide() {
        override val photos: List<PhotoRef> get() = listOf(photo)
    }

    data class Duo(val left: PhotoRef, val right: PhotoRef) : Slide() {
        override val photos: List<PhotoRef> get() = listOf(left, right)
    }
}

/**
 * Shuffle bag: each photo shows once per round (favourites twice) before anything repeats.
 * Drawing a portrait pulls the next portrait in the bag forward so the two share the screen.
 * Keeps a short history so Left and Right on the remote can step back and forth.
 */
class SlidePlanner(private val random: Random = Random.Default) {
    private var photos: List<PhotoRef> = emptyList()
    private val bag = ArrayDeque<PhotoRef>()
    private val history = ArrayList<Slide>()
    private var cursor = -1

    /**
     * Replaces the photo set. Photos added to an existing set go to the front of the bag so they
     * show next; a wholly different set (built-ins giving way to the library) starts a fresh shuffle.
     */
    fun setPhotos(list: List<PhotoRef>) {
        val before = photos.map { it.id }.toSet()
        photos = list.distinctBy { it.id }
        val byId = photos.associateBy { it.id }
        val kept = bag.mapNotNull { byId[it.id] }
        bag.clear()
        if (photos.any { it.id in before }) bag.addAll(photos.filter { it.id !in before })
        bag.addAll(kept)
        history.removeAll { slide -> slide.photos.any { it.id !in byId } }
        cursor = history.lastIndex
    }

    fun next(): Slide? {
        if (cursor < history.lastIndex) {
            cursor++
            return history[cursor]
        }
        val slide = draw() ?: return null
        history.add(slide)
        if (history.size > HISTORY) history.removeAt(0)
        cursor = history.lastIndex
        return slide
    }

    fun previous(): Slide? {
        if (cursor <= 0) return null
        cursor--
        return history[cursor]
    }

    private fun draw(): Slide? {
        if (photos.isEmpty()) return null
        if (bag.isEmpty()) refill()
        val first = bag.removeFirst()
        if (!first.portrait) return Slide.Single(first)
        val partner = bag.indexOfFirst { it.portrait && it.id != first.id }
        return if (partner < 0) Slide.Single(first) else Slide.Duo(first, bag.removeAt(partner))
    }

    private fun refill() {
        val round = photos.flatMap { if (it.favorite) listOf(it, it) else listOf(it) }.shuffled(random).toMutableList()
        // Don't open a round with what closed the last one.
        val last = history.lastOrNull()?.photos?.map { it.id }.orEmpty()
        if (round.size > 1 && round[0].id in last) {
            val j = round.indexOfFirst { it.id !in last }
            if (j > 0) round[0] = round[j].also { round[j] = round[0] }
        }
        // Keep a favourite's two copies apart: move the second copy to the first spot not next to its twin.
        var i = 1
        while (i < round.size) {
```

```kotlin file=core/src/main/kotlin/io/github/shalintripathi/canvas/core/Captions.kt
object Captions {
    private const val DAY_MS = 24L * 60 * 60 * 1000

    /** "March 2023 · 3 years ago"; just "June 2026" for photos under a year old; null without a date. */
    fun forPhoto(
        takenAt: Long?,
        now: Long,
        locale: Locale = Locale.getDefault(),
        zone: TimeZone = TimeZone.getDefault(),
    ): String? {
        if (takenAt == null || takenAt <= 0 || takenAt > now + DAY_MS) return null
        val month = SimpleDateFormat("MMMM yyyy", locale).apply { timeZone = zone }.format(Date(takenAt))
        return when (val years = yearsBetween(takenAt, now, zone)) {
            0 -> month
            1 -> "$month · 1 year ago"
            else -> "$month · $years years ago"
        }
    }

    /** Whole years from [from] to [to]; a year counts once its anniversary has passed. */
    fun yearsBetween(from: Long, to: Long, zone: TimeZone): Int {
        val a = Calendar.getInstance(zone).apply { timeInMillis = from }
        val b = Calendar.getInstance(zone).apply { timeInMillis = to }
        var years = b.get(Calendar.YEAR) - a.get(Calendar.YEAR)
        val beforeAnniversary = b.get(Calendar.MONTH) < a.get(Calendar.MONTH) ||
            (b.get(Calendar.MONTH) == a.get(Calendar.MONTH) &&
                b.get(Calendar.DAY_OF_MONTH) < a.get(Calendar.DAY_OF_MONTH))
        if (beforeAnniversary) years--
        return maxOf(0, years)
    }
```

```kotlin file=core/src/main/kotlin/io/github/shalintripathi/canvas/core/http/Http.kt
package io.github.shalintripathi.canvas.core.http

import java.io.ByteArrayOutputStream
import java.io.EOFException
import java.io.File
import java.io.InputStream
import java.net.URLDecoder

class HttpException(val status: Int, message: String) : Exception(message)

class HttpRequest(
    val method: String,
    val path: String,
    val query: Map<String, String>,
    val headers: Map<String, String>,
    val contentLength: Long,
    val body: InputStream,
) {
    fun header(name: String): String? = headers[name.lowercase()]

    val cookies: Map<String, String> by lazy {
        header("cookie").orEmpty().split(';').mapNotNull { part ->
            val eq = part.indexOf('=')
            if (eq <= 0) null else part.substring(0, eq).trim() to part.substring(eq + 1).trim()
        }.toMap()
    }

    /** A small body (JSON forms) as UTF-8. */
    fun bodyText(limit: Int = 64 * 1024): String {
        if (contentLength > limit) throw HttpException(413, "Body too large")
        return body.readBytes().toString(Charsets.UTF_8)
    }
}

class HttpResponse(
    val status: Int,
    val contentType: String,
    val body: ByteArray = ByteArray(0),
    val file: File? = null,
    val headers: Map<String, String> = emptyMap(),
) {
    companion object {
        private const val JSON = "application/json; charset=utf-8"

        fun json(json: String, status: Int = 200, headers: Map<String, String> = emptyMap()) =
            HttpResponse(status, JSON, json.toByteArray(Charsets.UTF_8), headers = headers)

        fun error(status: Int, message: String) = json("{\"error\":${quote(message)}}", status)

        fun bytes(bytes: ByteArray, type: String, headers: Map<String, String> = emptyMap()) =
            HttpResponse(200, type, bytes, headers = headers)

        fun file(file: File, type: String, headers: Map<String, String> = emptyMap()) =
            HttpResponse(200, type, file = file, headers = headers)

        fun redirect(location: String, headers: Map<String, String> = emptyMap()) =
            HttpResponse(302, "text/plain; charset=utf-8", headers = headers + ("Location" to location))

        /** A JSON string literal. */
        fun quote(s: String): String {
            val out = StringBuilder(s.length + 2).append('"')
            for (c in s) when {
                c == '"' -> out.append("\\\"")
                c == '\\' -> out.append("\\\\")
                c == '\n' -> out.append("\\n")
                c == '\r' -> out.append("\\r")
                c == '\t' -> out.append("\\t")
                c < ' ' -> out.append(String.format("\\u%04x", c.code))
                else -> out.append(c)
            }
            return out.append('"').toString()
        }
    }
}

fun interface HttpHandler {
    fun handle(request: HttpRequest): HttpResponse
}

/** Body stream that stops after Content-Length bytes and never closes the socket. */
class LimitedInputStream(private val input: InputStream, private var remaining: Long) : InputStream() {
    override fun read(): Int {
        if (remaining <= 0) return -1
        val b = input.read()
        if (b < 0) remaining = 0 else remaining--
        return b
    }

    override fun read(b: ByteArray, off: Int, len: Int): Int {
        if (remaining <= 0) return -1
        val n = input.read(b, off, minOf(len.toLong(), remaining).toInt())
        if (n < 0) remaining = 0 else remaining -= n
        return n
    }

    override fun close() = Unit
}

object HttpParser {
    const val MAX_HEAD = 16 * 1024
    private const val CR = '\r'.code
    private const val LF = '\n'.code

    fun parse(input: InputStream, maxBody: Long): HttpRequest {
        val lines = readHead(input).split("\r\n")
        val parts = lines.first().split(' ')
        if (parts.size != 3 || !parts[2].startsWith("HTTP/1.")) throw HttpException(400, "Bad request line")
        val target = parts[1]
        if (!target.startsWith("/")) throw HttpException(400, "Bad request target")
        val q = target.indexOf('?')
        val path = decode(if (q < 0) target else target.substring(0, q), keepPlus = true)
        val query = if (q < 0) emptyMap() else parseQuery(target.substring(q + 1))

        val headers = HashMap<String, String>()
        for (line in lines.drop(1)) {
            if (line.isEmpty()) continue
            val colon = line.indexOf(':')
            if (colon <= 0) throw HttpException(400, "Bad header")
            headers[line.substring(0, colon).trim().lowercase()] = line.substring(colon + 1).trim()
        }
        if (headers.containsKey("transfer-encoding")) throw HttpException(501, "Chunked bodies are not supported")
        val length = headers["content-length"]?.let { it.toLongOrNull() ?: throw HttpException(400, "Bad Content-Length") } ?: 0L
        if (length < 0) throw HttpException(400, "Bad Content-Length")
        if (length > maxBody) throw HttpException(413, "Body too large")
        return HttpRequest(parts[0].uppercase(), path, query, headers, length, LimitedInputStream(input, length))
    }

    private fun readHead(input: InputStream): String {
        val buf = ByteArrayOutputStream()
        var matched = 0 // how much of "\r\n\r\n" has been seen
        while (matched < 4) {
            val b = input.read()
            if (b < 0) {
                if (buf.size() == 0) throw EOFException()
                throw HttpException(400, "Incomplete request")
            }
            buf.write(b)
            if (buf.size() > MAX_HEAD) throw HttpException(431, "Headers too large")
            matched = when (matched) {
                0, 2 -> if (b == CR) matched + 1 else 0
                else -> if (b == LF) matched + 1 else if (b == CR) 1 else 0
            }
        }
        val bytes = buf.toByteArray()
        return String(bytes, 0, bytes.size - 4, Charsets.ISO_8859_1)
    }

    private fun parseQuery(s: String): Map<String, String> = s.split('&').filter { it.isNotEmpty() }.associate { pair ->
        val eq = pair.indexOf('=')
        if (eq < 0) decode(pair) to "" else decode(pair.substring(0, eq)) to decode(pair.substring(eq + 1))
    }

    private fun decode(s: String, keepPlus: Boolean = false): String = try {
        URLDecoder.decode(if (keepPlus) s.replace("+", "%2B") else s, "UTF-8")
    } catch (e: IllegalArgumentException) {
        throw HttpException(400, "Bad percent-encoding")
    }
}
```

```kotlin file=core/src/main/kotlin/io/github/shalintripathi/canvas/core/http/HttpServer.kt
package io.github.shalintripathi.canvas.core.http

import java.io.BufferedInputStream
import java.io.BufferedOutputStream
import java.io.EOFException
import java.io.IOException
import java.io.OutputStream
import java.net.InetSocketAddress
import java.net.ServerSocket
import java.net.Socket
import java.net.SocketTimeoutException
import java.util.concurrent.ExecutorService
import java.util.concurrent.Executors
import java.util.concurrent.RejectedExecutionException

/** One request per connection (Connection: close), handled on a small thread pool. */
class HttpServer(
    private val port: Int,
    private val maxBody: Long,
    private val handler: HttpHandler,
    private val threads: Int = 4,
) {
    private var server: ServerSocket? = null
    private var pool: ExecutorService? = null

    val localPort: Int get() = server?.localPort ?: -1

    @Synchronized
    fun start() {
        if (server != null) return
        val socket = ServerSocket()
        socket.reuseAddress = true
        socket.bind(InetSocketAddress(port))
        val workers = Executors.newFixedThreadPool(threads)
        server = socket
        pool = workers
        Thread({ acceptLoop(socket, workers) }, "canvas-http").apply { isDaemon = true }.start()
    }

    @Synchronized
    fun stop() {
        server?.close()
        server = null
        pool?.shutdownNow()
        pool = null
    }

    private fun acceptLoop(socket: ServerSocket, workers: ExecutorService) {
        while (!socket.isClosed) {
            val client = try {
                socket.accept()
            } catch (e: IOException) {
                return
            }
            try {
                workers.execute { serve(client) }
            } catch (e: RejectedExecutionException) {
                client.close()
            }
        }
    }

    private fun serve(client: Socket) {
        client.use {
            it.soTimeout = 30_000
            val input = BufferedInputStream(it.getInputStream())
            val output = BufferedOutputStream(it.getOutputStream())
            val response = try {
                handler.handle(HttpParser.parse(input, maxBody))
            } catch (e: EOFException) {
                return
            } catch (e: SocketTimeoutException) {
                return
            } catch (e: HttpException) {
                HttpResponse.error(e.status, e.message ?: "Error")
            } catch (e: Exception) {
                HttpResponse.error(500, "Internal error")
            }
            try {
                write(output, response)
            } catch (e: IOException) {
                // The phone went away mid-response.
            }
        }
    }

    companion object {
        fun write(out: OutputStream, r: HttpResponse) {
            val length = r.file?.length() ?: r.body.size.toLong()
            val head = StringBuilder()
                .append("HTTP/1.1 ").append(r.status).append(' ').append(reason(r.status)).append("\r\n")
                .append("Content-Type: ").append(r.contentType).append("\r\n")
                .append("Content-Length: ").append(length).append("\r\n")
                .append("Connection: close\r\n")
                .append("X-Content-Type-Options: nosniff\r\n")
            if (r.headers.keys.none { it.equals("Cache-Control", ignoreCase = true) }) head.append("Cache-Control: no-store\r\n")
            for ((name, value) in r.headers) head.append(name).append(": ").append(value).append("\r\n")
            head.append("\r\n")
            out.write(head.toString().toByteArray(Charsets.ISO_8859_1))
            val file = r.file
            if (file != null) file.inputStream().use { it.copyTo(out) } else out.write(r.body)
            out.flush()
        }

        private fun reason(status: Int) = when (status) {
            200 -> "OK"
            201 -> "Created"
            302 -> "Found"
            400 -> "Bad Request"
            401 -> "Unauthorized"
            403 -> "Forbidden"
            404 -> "Not Found"
            409 -> "Conflict"
            410 -> "Gone"
            413 -> "Payload Too Large"
            415 -> "Unsupported Media Type"
            431 -> "Request Header Fields Too Large"
            501 -> "Not Implemented"
            else -> if (status >= 500) "Server Error" else "Status"
        }
    }
}
```

```kotlin file=core/src/main/kotlin/io/github/shalintripathi/canvas/core/Pairing.kt
package io.github.shalintripathi.canvas.core

import java.security.MessageDigest
import java.security.SecureRandom

/** A paired phone. Only the SHA-256 of its session is kept. */
data class Phone(val hash: String, val label: String, val pairedAt: Long) {
    val id: String get() = hash.take(12)
}

interface PhoneStore {
    fun load(): List<Phone>
    fun save(phones: List<Phone>)
}

/**
 * Pairing for the phone page. The TV shows a QR code (carrying [Code.token]) and a PIN for typing
 * by hand. Either one, while fresh, turns into a long-lived session cookie for that phone.
 */
class Pairing(
    private val store: PhoneStore,
    private val clock: () -> Long = System::currentTimeMillis,
    private val random: SecureRandom = SecureRandom(),
) {
    data class Code(val token: String, val pin: String, val expiresAt: Long)

    sealed class PinResult {
        data class Paired(val session: String) : PinResult()
        data class Wrong(val attemptsLeft: Int) : PinResult()
        object NoCode : PinResult()
    }

    private var code: Code? = null
    private var wrongPins = 0
    private val phones: MutableList<Phone> = store.load().toMutableList()

    @Synchronized
    fun newCode(): Code {
        val pin = random.nextInt(1_000_000).toString().padStart(6, '0')
        return Code(hex(bytes(16)), pin, clock() + CODE_TTL_MS).also {
            code = it
            wrongPins = 0
        }
    }

    @Synchronized
    fun currentCode(): Code? = code?.takeIf { clock() < it.expiresAt }

    @Synchronized
    fun pairWithToken(token: String, label: String): String? {
        val c = currentCode() ?: return null
        return if (same(token, c.token)) addPhone(label) else null
    }

    @Synchronized
    fun pairWithPin(pin: String, label: String): PinResult {
        val c = currentCode() ?: return PinResult.NoCode
        if (same(pin.trim(), c.pin)) return PinResult.Paired(addPhone(label))
        wrongPins++
        if (wrongPins >= MAX_WRONG_PINS) {
            code = null
            return PinResult.NoCode
        }
        return PinResult.Wrong(MAX_WRONG_PINS - wrongPins)
    }

    @Synchronized
    fun isPaired(session: String?): Boolean = phoneFor(session) != null

    @Synchronized
    fun phoneFor(session: String?): Phone? {
        if (session.isNullOrEmpty()) return null
        val hash = sha256(session)
        return phones.firstOrNull { same(it.hash, hash) }
    }

    @Synchronized
    fun phones(): List<Phone> = phones.toList()

    @Synchronized
    fun revoke(id: String): Boolean {
        val removed = phones.removeAll { it.id == id }
        if (removed) store.save(phones.toList())
        return removed
    }

    private fun addPhone(label: String): String {
        val session = hex(bytes(32))
        phones.add(Phone(sha256(session), label, clock()))
        while (phones.size > MAX_PHONES) phones.removeAt(0)
        store.save(phones.toList())
        return session
    }

    private fun bytes(n: Int) = ByteArray(n).also { random.nextBytes(it) }

    companion object {
        const val CODE_TTL_MS = 10 * 60 * 1000L
        const val MAX_WRONG_PINS = 5
        const val MAX_PHONES = 20

        fun sha256(s: String): String = hex(MessageDigest.getInstance("SHA-256").digest(s.toByteArray(Charsets.UTF_8)))

        fun deviceLabel(userAgent: String?): String {
            val ua = userAgent.orEmpty()
            return when {
                "iPhone" in ua -> "iPhone"
                "iPad" in ua -> "iPad"
                "Android" in ua -> "Android phone"
                "Macintosh" in ua -> "Mac or iPad"
                "Windows" in ua -> "Windows PC"
                else -> "Browser"
            }
        }

        private fun hex(bytes: ByteArray): String {
            val digits = "0123456789abcdef"
            val out = StringBuilder(bytes.size * 2)
            for (b in bytes) {
                val v = b.toInt() and 0xff
                out.append(digits[v ushr 4]).append(digits[v and 0x0f])
            }
            return out.toString()
        }

        private fun same(a: String, b: String) = MessageDigest.isEqual(a.toByteArray(), b.toByteArray())
    }
}
```

```kotlin file=core/src/main/kotlin/io/github/shalintripathi/canvas/core/Library.kt
import org.json.JSONArray
import org.json.JSONException
import org.json.JSONObject
import java.security.SecureRandom

/** One photo stored on the TV. [width] and [height] are of the stored, upright JPEG. */
data class PhotoEntry(
    val id: String,
    val addedAt: Long,
    val takenAt: Long?,
    val width: Int,
    val height: Int,
    val favorite: Boolean = false,
    val source: String = "phone",
) {
    val portrait: Boolean get() = height > width

    fun toRef() = PhotoRef(id, portrait, favorite)
}

object LibraryJson {
    private val ID = Regex("[a-z0-9]{12}")
    private const val ALPHABET = "abcdefghijklmnopqrstuvwxyz0123456789"
    private val random = SecureRandom()

    /** Ids name files on disk, so anything else is rejected. */
    fun isValidId(id: String) = ID.matches(id)

    fun newId(): String = String(CharArray(12) { ALPHABET[random.nextInt(ALPHABET.length)] })

    fun toJson(e: PhotoEntry): JSONObject = JSONObject()
        .put("id", e.id)
        .put("addedAt", e.addedAt)
        .put("takenAt", e.takenAt ?: JSONObject.NULL)
        .put("width", e.width)
        .put("height", e.height)
        .put("favorite", e.favorite)
        .put("source", e.source)

    fun encode(entries: List<PhotoEntry>): String = JSONArray().apply { entries.forEach { put(toJson(it)) } }.toString()

    fun decode(text: String): List<PhotoEntry> = try {
        val array = JSONArray(text)
        (0 until array.length()).mapNotNull { i ->
            val o = array.optJSONObject(i) ?: return@mapNotNull null
            val id = o.optString("id")
            val width = o.optInt("width")
            val height = o.optInt("height")
            if (!isValidId(id) || width <= 0 || height <= 0) return@mapNotNull null
            PhotoEntry(
                id = id,
                addedAt = o.optLong("addedAt"),
                takenAt = if (o.isNull("takenAt")) null else o.optLong("takenAt"),
                width = width,
                height = height,
                favorite = o.optBoolean("favorite"),
                source = o.optString("source", "phone"),
            )
        }
    } catch (e: JSONException) {
        emptyList()
    }
}

object PhonesJson {
    fun encode(phones: List<Phone>): String = JSONArray().apply {
        phones.forEach { put(JSONObject().put("hash", it.hash).put("label", it.label).put("pairedAt", it.pairedAt)) }
    }.toString()

    fun decode(text: String): List<Phone> = try {
        val array = JSONArray(text)
        (0 until array.length()).mapNotNull { i ->
            val o = array.optJSONObject(i) ?: return@mapNotNull null
            val hash = o.optString("hash")
            if (hash.length != 64) null else Phone(hash, o.optString("label", "Browser"), o.optLong("pairedAt"))
        }
    } catch (e: JSONException) {
        emptyList()
    }
}
```

```kotlin file=core/src/main/kotlin/io/github/shalintripathi/canvas/core/HomeLayout.kt
package io.github.shalintripathi.canvas.core

/** The owner's dock order and hidden apps, by package name. */
data class HomeLayout(val dock: List<String>, val hidden: Set<String>) {

    fun moveLeft(pkg: String) = move(pkg, -1)

    fun moveRight(pkg: String) = move(pkg, 1)

    fun addToDock(pkg: String): HomeLayout =
        if (pkg in dock || dock.size >= MAX_DOCK) this else copy(dock = dock + pkg, hidden = hidden - pkg)

    fun removeFromDock(pkg: String) = copy(dock = dock - pkg)

    fun hide(pkg: String) = copy(dock = dock - pkg, hidden = hidden + pkg)

    fun unhide(pkg: String) = copy(hidden = hidden - pkg)

    /** Splits installed apps (already in grid order) into the dock, in dock order, and the grid. */
    fun arrange(installed: List<String>): Pair<List<String>, List<String>> {
        val present = installed.toSet()
        val dockApps = dock.filter { it in present && it !in hidden }
        val inDock = dockApps.toSet()
        return dockApps to installed.filter { it !in inDock && it !in hidden }
    }

    private fun move(pkg: String, delta: Int): HomeLayout {
        val i = dock.indexOf(pkg)
        val j = i + delta
        if (i < 0 || j !in dock.indices) return this
        val d = dock.toMutableList()
        d[i] = d[j].also { d[j] = d[i] }
        return copy(dock = d)
    }

    companion object {
        const val MAX_DOCK = 7

        val PREFERRED = listOf(
            "com.google.android.youtube.tv",
            "com.netflix.ninja",
            "com.amazon.amazonvideo.livingroom",
            "in.startv.hotstar",
            "com.apple.atve.androidtv.appletv",
        )

        fun defaults(installed: Collection<String>) = HomeLayout(PREFERRED.filter { it in installed }, emptySet())
    }
}
```

```kotlin file=app/src/main/kotlin/io/github/shalintripathi/canvas/util/Network.kt
package io.github.shalintripathi.canvas.util

import android.content.Context
import android.net.ConnectivityManager
import android.net.NetworkCapabilities
import android.net.wifi.WifiManager
import java.net.Inet4Address
import java.net.NetworkInterface
import java.net.SocketException

object Network {
    /** The TV's address on the home network, preferring Wi-Fi, then Ethernet. */
    fun localIpv4(): String? = try {
        NetworkInterface.getNetworkInterfaces()?.toList().orEmpty()
            .filter { it.isUp && !it.isLoopback }
            .sortedBy { if (it.name.startsWith("wlan")) 0 else if (it.name.startsWith("eth")) 1 else 2 }
            .flatMap { it.inetAddresses.toList() }
            .firstOrNull { it is Inet4Address && it.isSiteLocalAddress }
            ?.hostAddress
    } catch (e: SocketException) {
        null
    }

    /** "Ethernet", the Wi-Fi name, "Wi-Fi" when the name is hidden from us, or "Offline". */
    @Suppress("DEPRECATION")
    fun name(context: Context): String {
        val cm = context.getSystemService(ConnectivityManager::class.java) ?: return "Network"
        val caps = cm.getNetworkCapabilities(cm.activeNetwork) ?: return "Offline"
        if (caps.hasTransport(NetworkCapabilities.TRANSPORT_ETHERNET)) return "Ethernet"
        if (!caps.hasTransport(NetworkCapabilities.TRANSPORT_WIFI)) return "Online"
        val ssid = try {
            (context.applicationContext.getSystemService(Context.WIFI_SERVICE) as WifiManager).connectionInfo?.ssid
        } catch (e: SecurityException) {
            null
        }
        return ssid?.removeSurrounding("\"")?.takeIf { it.isNotBlank() && it != "<unknown ssid>" } ?: "Wi-Fi"
    }
}
```

```kotlin file=app/src/main/kotlin/io/github/shalintripathi/canvas/settings/SystemSettings.kt
import android.Manifest
import android.content.ComponentName
import android.content.Context
import android.content.pm.PackageManager
import android.provider.Settings

/**
 * Screensaver and timeout settings. Writing needs WRITE_SECURE_SETTINGS and WRITE_SETTINGS, which
 * `tools/canvas install` grants over ADB. Android 12+ hides some Secure settings from apps, so reads
 * may come back null; writes still work.
 */
class SystemSettings(private val context: Context) {
    private val resolver = context.contentResolver
    val dream = ComponentName(context.packageName, DREAM_CLASS)

    fun canWriteSecure(): Boolean =
        context.checkSelfPermission(Manifest.permission.WRITE_SECURE_SETTINGS) == PackageManager.PERMISSION_GRANTED

    fun canWriteSystem(): Boolean = Settings.System.canWrite(context)

    fun canChange(): Boolean = canWriteSecure() && canWriteSystem()

    /** True or false when readable; null when the TV hides the setting from apps. */
    fun isCanvasScreensaver(): Boolean? = readSecure(SCREENSAVER_COMPONENTS)?.let { value ->
        value.split(',').firstOrNull()?.let { ComponentName.unflattenFromString(it) } == dream
    }

    fun useCanvas(): Boolean = canWriteSecure() &&
        putSecure(SCREENSAVER_COMPONENTS, dream.flattenToString()) &&
        putSecure(SCREENSAVER_ENABLED, "1") &&
        putSecure(SCREENSAVER_ON_SLEEP, "1")

    fun restorePrevious(prefs: Prefs): Boolean {
        if (!canWriteSecure()) return false
        val previous = prefs.previousScreensaver
        return if (previous != null) putSecure(SCREENSAVER_COMPONENTS, previous) else putSecure(SCREENSAVER_ENABLED, "0")
    }

    /** Called at startup: note the TV's own screensaver once, before Canvas replaces it. */
    fun rememberPrevious(prefs: Prefs) {
        if (prefs.previousScreensaver != null) return
        val current = readSecure(SCREENSAVER_COMPONENTS) ?: return
        if (current.isNotEmpty() && !current.startsWith(context.packageName)) prefs.previousScreensaver = current
    }

    /** Puts Canvas back as the screensaver if a TV update or Google's Ambient settings replaced it. */
    fun repair(prefs: Prefs) {
        if (prefs.useCanvasScreensaver && canWriteSecure() && isCanvasScreensaver() != true) useCanvas()
    }

    fun startAfterMinutes(): Int =
        Settings.System.getInt(resolver, Settings.System.SCREEN_OFF_TIMEOUT, 600_000) / 60_000

    fun setStartAfterMinutes(minutes: Int): Boolean = canWriteSystem() && try {
        Settings.System.putInt(resolver, Settings.System.SCREEN_OFF_TIMEOUT, minutes * 60_000)
    } catch (e: RuntimeException) {
        false
    }

    /** Minutes on the screensaver before the TV sleeps; -1 means never. */
    fun turnOffAfterMinutes(prefs: Prefs): Int {
        val ms = readSecure(SLEEP_TIMEOUT)?.toIntOrNull() ?: prefs.turnOffAfterMs
        return if (ms < 0) -1 else ms / 60_000
    }

    fun setTurnOffAfterMinutes(minutes: Int, prefs: Prefs): Boolean {
        val ms = if (minutes < 0) -1 else minutes * 60_000
        val ok = canWriteSecure() && putSecure(SLEEP_TIMEOUT, ms.toString())
        if (ok) prefs.turnOffAfterMs = ms
        return ok
    }

    private fun readSecure(key: String): String? = try {
        Settings.Secure.getString(resolver, key)
    } catch (e: SecurityException) {
        null
    }

    private fun putSecure(key: String, value: String): Boolean = try {
        Settings.Secure.putString(resolver, key, value)
    } catch (e: RuntimeException) {
        false
    }

    companion object {
        const val DREAM_CLASS = "io.github.shalintripathi.canvas.frame.FrameDreamService"
        private const val SCREENSAVER_COMPONENTS = "screensaver_components"
        private const val SCREENSAVER_ENABLED = "screensaver_enabled"
        private const val SCREENSAVER_ON_SLEEP = "screensaver_activate_on_sleep"
        private const val SLEEP_TIMEOUT = "sleep_timeout"
    }
}
```

```kotlin file=app/src/main/kotlin/io/github/shalintripathi/canvas/apps/AppRepository.kt
/** Installed TV apps: everything with a Leanback launcher entry. */
class AppRepository(private val context: Context) {
    private val pm = context.packageManager
    private val colors = ConcurrentHashMap<String, Int>()

    @Volatile
    private var sequence = 0

    /** True if packages were installed, removed or changed since [markSeen]. Always true before Android 8. */
    fun hasChanges(): Boolean = Build.VERSION.SDK_INT < 26 || pm.getChangedPackages(sequence) != null

    fun markSeen() {
        if (Build.VERSION.SDK_INT >= 26) pm.getChangedPackages(sequence)?.let { sequence = it.sequenceNumber }
    }

    /** One entry per package, sorted by label, with banner art and a glow colour. */
    fun load(excluded: Set<String>): List<AppInfo> {
        val byPkg = LinkedHashMap<String, AppInfo>()
        for (ri in pm.queryIntentActivities(leanback(), 0)) {
            val ai = ri.activityInfo
            if (ai.packageName in excluded || byPkg.containsKey(ai.packageName)) continue
            val banner = ai.loadBanner(pm) ?: ai.applicationInfo.loadBanner(pm)
            val art = banner ?: ri.loadIcon(pm)
            byPkg[ai.packageName] = AppInfo(
                ai.packageName, ri.loadLabel(pm).toString(), ComponentName(ai.packageName, ai.name),
                art, banner != null, sampleColor(ai.packageName, art),
            )
        }
        return byPkg.values.sortedWith(compareBy(String.CASE_INSENSITIVE_ORDER) { it.label })
    }

    /** Package and label only: cheap enough for the phone page. */
    fun labels(excluded: Set<String>): List<Pair<String, String>> =
        pm.queryIntentActivities(leanback(), 0)
            .map { it.activityInfo.packageName to it.loadLabel(pm).toString() }
            .filter { it.first !in excluded }
            .distinctBy { it.first }
            .sortedWith(compareBy(String.CASE_INSENSITIVE_ORDER) { it.second })

    /** Never shown as tiles: Canvas itself, Settings (a pill) and the Live TV app (in Inputs). */
    fun excludedPackages(): Set<String> = setOf(context.packageName, TV_SETTINGS) + LIVE_TV.filter { isInstalled(it) }

    fun liveTvPackage(): String? = LIVE_TV.firstOrNull { isInstalled(it) }

    fun isInstalled(pkg: String): Boolean = try {
        pm.getPackageInfo(pkg, 0)
        true
    } catch (e: PackageManager.NameNotFoundException) {
        false
    }

    fun launchIntent(pkg: String): Intent? = pm.getLeanbackLaunchIntentForPackage(pkg) ?: pm.getLaunchIntentForPackage(pkg)

    /** The app's banner, or its icon on a tinted card, as a PNG for the phone page. */
    fun artPng(pkg: String, width: Int = 320, height: Int = 180): ByteArray? {
        val component = pm.getLeanbackLaunchIntentForPackage(pkg)?.component ?: return null
        val banner = try {
            pm.getActivityBanner(component) ?: pm.getApplicationBanner(pkg)
        } catch (e: PackageManager.NameNotFoundException) {
            null
        }
        val art = banner ?: try {
            pm.getActivityIcon(component)
        } catch (e: PackageManager.NameNotFoundException) {
            return null
        }
        val bitmap = Bitmap.createBitmap(width, height, Bitmap.Config.ARGB_8888)
        val canvas = Canvas(bitmap)
        if (banner != null) {
            art.setBounds(0, 0, width, height)
        } else {
            canvas.drawColor(darken(sampleColor(pkg, art), 0.45f))
            val size = height * 2 / 3
            art.setBounds((width - size) / 2, (height - size) / 2, (width + size) / 2, (height + size) / 2)
        }
        art.draw(canvas)
        val out = ByteArrayOutputStream()
        bitmap.compress(Bitmap.CompressFormat.PNG, 100, out)
        bitmap.recycle()
        return out.toByteArray()
    }

    /** Average the art's vivid pixels, then push saturation so the glow reads as a colour. */
    private fun sampleColor(pkg: String, drawable: Drawable): Int = colors.getOrPut(pkg) {
        try {
            val bitmap = Bitmap.createBitmap(24, 14, Bitmap.Config.ARGB_8888)
            drawable.setBounds(0, 0, 24, 14)
            drawable.draw(Canvas(bitmap))
            val hsv = FloatArray(3)
            var r = 0.0
            var g = 0.0
            var b = 0.0
            var weight = 0.0
            for (y in 0 until 14) for (x in 0 until 24) {
                val p = bitmap.getPixel(x, y)
                if (Color.alpha(p) < 128) continue
                Color.colorToHSV(p, hsv)
                val w = 0.05 + hsv[1] * hsv[2]
                r += Color.red(p) * w
                g += Color.green(p) * w
                b += Color.blue(p) * w
                weight += w
            }
            bitmap.recycle()
            if (weight == 0.0) {
                DEFAULT_COLOR
            } else {
                Color.colorToHSV(Color.rgb((r / weight).toInt(), (g / weight).toInt(), (b / weight).toInt()), hsv)
                if (hsv[1] > 0.12f) {
                    hsv[1] = maxOf(hsv[1], 0.75f)
                    hsv[2] = 0.85f
                } else {
                    hsv[1] = 0f
                    hsv[2] = 0.45f
                }
                Color.HSVToColor(hsv)
            }
        } catch (e: RuntimeException) {
            DEFAULT_COLOR
        }
    }

    companion object {
        const val DEFAULT_COLOR = 0xFF3A3A3A.toInt()
        private const val TV_SETTINGS = "com.android.tv.settings"

        /** Live TV / tuner apps, most specific first. */
        val LIVE_TV = listOf(
            "com.mediatek.tv.oneworld.tvcenter",
            "com.mediatek.wwtv.tvcenter",
            "com.tcl.tv",
            "com.sony.dtv.tvx",
            "com.google.android.tv",
        )

        private fun leanback() = Intent(Intent.ACTION_MAIN).addCategory(Intent.CATEGORY_LEANBACK_LAUNCHER)
    }
}
```

```kotlin file=app/src/main/kotlin/io/github/shalintripathi/canvas/library/PhotoLibrary.kt
package io.github.shalintripathi.canvas.library

import android.content.Context
import android.graphics.Bitmap
import android.graphics.BitmapFactory
import android.graphics.Matrix
import android.media.ExifInterface
import android.os.Handler
import android.os.Looper
import io.github.shalintripathi.canvas.core.ImageMath
import io.github.shalintripathi.canvas.core.LibraryJson
import io.github.shalintripathi.canvas.core.PhotoEntry
import io.github.shalintripathi.canvas.util.writeAtomically
import java.io.File
import java.io.FileOutputStream
import java.io.IOException
import java.io.InputStream
import java.text.ParseException
import java.text.SimpleDateFormat
import java.util.Locale
import java.util.concurrent.CopyOnWriteArrayList

/** Photos added from phones: upright JPEGs in files/photos, thumbnails in files/thumbs, index in library.json. */
class PhotoLibrary(private val context: Context) {

    class UnsupportedImageException(message: String) : Exception(message)

    private val photos = File(context.filesDir, "photos").apply { mkdirs() }
    private val thumbs = File(context.filesDir, "thumbs").apply { mkdirs() }
    private val index = File(context.filesDir, "library.json")
    private val importLock = Any()
    private val listeners = CopyOnWriteArrayList<() -> Unit>()
    private val main = Handler(Looper.getMainLooper())

    @Volatile
    private var entries: List<PhotoEntry> = load()

    fun all(): List<PhotoEntry> = entries

    fun get(id: String): PhotoEntry? = entries.firstOrNull { it.id == id }

    fun photoFile(id: String) = File(photos, "$id.jpg")

    fun thumbFile(id: String) = File(thumbs, "$id.jpg")

    fun addListener(listener: () -> Unit) {
        listeners.add(listener)
    }

    fun removeListener(listener: () -> Unit) {
        listeners.remove(listener)
    }

    /** Stores one uploaded image. A body shorter than [length] means the upload broke off. */
    fun add(body: InputStream, length: Long, takenAtHint: Long?): PhotoEntry {
        val upload = File.createTempFile("upload", ".tmp", context.cacheDir)
        try {
            val copied = upload.outputStream().use { body.copyTo(it) }
            if (copied != length) throw IOException("Upload interrupted")
            // One import at a time: each one briefly holds a few full-size bitmaps.
            return synchronized(importLock) { import(upload, takenAtHint) }
        } finally {
            upload.delete()
        }
    }

    fun delete(id: String): Boolean {
        if (get(id) == null) return false
        update { list -> list.filter { it.id != id } }
        photoFile(id).delete()
        thumbFile(id).delete()
        return true
    }

    fun setFavorite(id: String, favorite: Boolean): Boolean {
        if (get(id) == null) return false
        update { list -> list.map { if (it.id == id) it.copy(favorite = favorite) else it } }
        return true
    }

    private fun import(file: File, takenAtHint: Long?): PhotoEntry {
        val bounds = BitmapFactory.Options().apply { inJustDecodeBounds = true }
        BitmapFactory.decodeFile(file.path, bounds)
        if (bounds.outWidth <= 0 || bounds.outHeight <= 0) throw UnsupportedImageException(UNSUPPORTED)

        val exif = try {
            ExifInterface(file.path)
        } catch (e: IOException) {
            null
        }
        val orientation = exif?.getAttributeInt(ExifInterface.TAG_ORIENTATION, ExifInterface.ORIENTATION_NORMAL)
            ?: ExifInterface.ORIENTATION_NORMAL
        val takenAt = exif?.let { exifDate(it) } ?: takenAtHint?.takeIf { it > 0 }

        val options = BitmapFactory.Options().apply {
            inSampleSize = ImageMath.sampleForLongSide(bounds.outWidth, bounds.outHeight, MAX_SIDE)
        }
        val decoded = decodeOrNull(file, options) ?: throw UnsupportedImageException(UNSUPPORTED)
        val photo = upright(scaled(decoded, MAX_SIDE), orientation)

        val id = LibraryJson.newId()
        writeJpeg(photo, photoFile(id), 88)
        writeJpeg(scaled(photo, THUMB_SIDE), thumbFile(id), 80)
        val entry = PhotoEntry(id, System.currentTimeMillis(), takenAt, photo.width, photo.height, false, "phone")
        update { it + entry }
        return entry
    }

    private fun decodeOrNull(file: File, options: BitmapFactory.Options): Bitmap? = try {
        BitmapFactory.decodeFile(file.path, options)
    } catch (e: OutOfMemoryError) {
        null
    }

    private fun scaled(bitmap: Bitmap, maxSide: Int): Bitmap {
        val (w, h) = ImageMath.fitLongSide(bitmap.width, bitmap.height, maxSide)
        return if (w == bitmap.width && h == bitmap.height) bitmap else Bitmap.createScaledBitmap(bitmap, w, h, true)
    }

    /** Applies the EXIF orientation so the stored JPEG is the right way up. */
    private fun upright(bitmap: Bitmap, orientation: Int): Bitmap {
        val m = Matrix()
        when (orientation) {
            ExifInterface.ORIENTATION_FLIP_HORIZONTAL -> m.setScale(-1f, 1f)
            ExifInterface.ORIENTATION_ROTATE_180 -> m.setRotate(180f)
            ExifInterface.ORIENTATION_FLIP_VERTICAL -> {
                m.setRotate(180f)
                m.postScale(-1f, 1f)
            }
            ExifInterface.ORIENTATION_TRANSPOSE -> {
                m.setRotate(90f)
                m.postScale(-1f, 1f)
            }
            ExifInterface.ORIENTATION_ROTATE_90 -> m.setRotate(90f)
            ExifInterface.ORIENTATION_TRANSVERSE -> {
                m.setRotate(-90f)
                m.postScale(-1f, 1f)
            }
            ExifInterface.ORIENTATION_ROTATE_270 -> m.setRotate(-90f)
            else -> return bitmap
        }
        return Bitmap.createBitmap(bitmap, 0, 0, bitmap.width, bitmap.height, m, true)
    }

    private fun writeJpeg(bitmap: Bitmap, target: File, quality: Int) {
        val tmp = File(target.parentFile, target.name + ".tmp")
        FileOutputStream(tmp).use {
            if (!bitmap.compress(Bitmap.CompressFormat.JPEG, quality, it)) throw IOException("JPEG encode failed")
        }
        if (!tmp.renameTo(target)) throw IOException("Could not save photo")
    }

    private fun exifDate(exif: ExifInterface): Long? {
        val raw = exif.getAttribute(ExifInterface.TAG_DATETIME_ORIGINAL)
            ?: exif.getAttribute(ExifInterface.TAG_DATETIME) ?: return null
        if (raw.startsWith("0000")) return null
        return try {
            SimpleDateFormat("yyyy:MM:dd HH:mm:ss", Locale.US).parse(raw)?.time
        } catch (e: ParseException) {
            null
        }
    }

    private fun update(change: (List<PhotoEntry>) -> List<PhotoEntry>) {
        synchronized(this) {
            entries = change(entries)
            index.writeAtomically(LibraryJson.encode(entries))
        }
        main.post { listeners.forEach { it() } }
    }

    private fun load(): List<PhotoEntry> =
        if (!index.exists()) emptyList() else LibraryJson.decode(index.readText()).filter { photoFile(it.id).exists() }

    companion object {
        const val MAX_SIDE = 1920
        const val THUMB_SIDE = 320
        private const val UNSUPPORTED = "This TV can't read that file. Try a JPEG or PNG photo."
    }
}
```

```kotlin file=app/src/main/kotlin/io/github/shalintripathi/canvas/frame/BitmapLoader.kt
package io.github.shalintripathi.canvas.frame

import android.content.Context
import android.graphics.Bitmap
import android.graphics.BitmapFactory
import io.github.shalintripathi.canvas.canvas
import io.github.shalintripathi.canvas.core.ImageMath
import io.github.shalintripathi.canvas.core.PhotoRef
import java.io.FileInputStream
import java.io.IOException
import java.io.InputStream

object BitmapLoader {
    private const val BUILTIN = "builtin:"

    /** The bundled nature photos (all landscape). */
    fun builtins(context: Context): List<PhotoRef> {
        val names = try {
            context.assets.list("wallpapers")
        } catch (e: IOException) {
            null
        }
        return names.orEmpty().filter { it.endsWith(".jpg") }.sorted().map { PhotoRef(BUILTIN + it, portrait = false) }
    }

    /** Decodes a library or built-in photo just big enough to fill [reqWidth] x [reqHeight]. */
    fun load(context: Context, id: String, reqWidth: Int, reqHeight: Int): Bitmap? = try {
        if (id.startsWith(BUILTIN)) {
            val name = "wallpapers/" + id.removePrefix(BUILTIN)
            decode({ context.assets.open(name) }, reqWidth, reqHeight)
        } else {
            val file = context.canvas().library.photoFile(id)
            if (file.exists()) decode({ FileInputStream(file) }, reqWidth, reqHeight) else null
        }
    } catch (e: IOException) {
        null
    }

    /** A tiny, softened copy to sit blurred behind a lone portrait. */
    fun backdrop(source: Bitmap): Bitmap {
        val w = 24
        val h = maxOf(1, w * source.height / source.width)
        val tiny = Bitmap.createScaledBitmap(source, w, h, true)
        return Bitmap.createScaledBitmap(tiny, w * 8, h * 8, true)
    }

    private fun decode(open: () -> InputStream, reqWidth: Int, reqHeight: Int): Bitmap? {
        val bounds = BitmapFactory.Options().apply { inJustDecodeBounds = true }
        open().use { BitmapFactory.decodeStream(it, null, bounds) }
        if (bounds.outWidth <= 0 || bounds.outHeight <= 0) return null
        val options = BitmapFactory.Options().apply {
            inSampleSize = ImageMath.sampleToFill(bounds.outWidth, bounds.outHeight, reqWidth, reqHeight)
        }
        return open().use { BitmapFactory.decodeStream(it, null, options) }
    }
}
```

```kotlin file=app/src/main/kotlin/io/github/shalintripathi/canvas/frame/OverlayView.kt
import android.content.Context
import android.graphics.Color
import android.graphics.drawable.GradientDrawable
import android.os.Handler
import android.os.Looper

import android.view.Gravity

import android.widget.FrameLayout

import java.text.SimpleDateFormat
import java.util.Date
import java.util.Locale
import java.util.Random

/** Clock and date in one corner, the photo's caption in the other. Drifts a little to avoid burn-in. */
class OverlayView(context: Context, showClock: Boolean) : FrameLayout(context) {
    private val main = Handler(Looper.getMainLooper())
    private val random = Random()
    private val block = FrameLayout(context)
    private val clock = context.text(46f, "sans-serif-light", Color.WHITE)
    private val date = context.text(13f, "sans-serif-medium", 0xCCFFFFFF.toInt())
    private val caption = context.text(16f, "sans-serif", 0xE6FFFFFF.toInt())

    private val tick = object : Runnable {
        override fun run() {
            updateClock()
            main.postDelayed(this, 60_000 - System.currentTimeMillis() % 60_000)
        }
    }
    private val shift = object : Runnable {
        override fun run() {
            moveBlock()
            main.postDelayed(this, SHIFT_MS)
        }
    }

    init {
        val scrim = View(context)
        scrim.background = GradientDrawable(GradientDrawable.Orientation.BOTTOM_TOP, intArrayOf(0x99000000.toInt(), 0))
        addView(scrim, LayoutParams(MATCH, dp(240), Gravity.BOTTOM))

        val corner = LinearLayout(context)
        corner.orientation = LinearLayout.VERTICAL
        corner.gravity = Gravity.END
        clock.includeFontPadding = false
        date.letterSpacing = 0.18f
        corner.addView(clock)
        corner.addView(date)
        corner.visibility = if (showClock) View.VISIBLE else View.GONE
        block.addView(corner, LayoutParams(WRAP, WRAP, Gravity.BOTTOM or Gravity.END))

        caption.alpha = 0f
        block.addView(caption, LayoutParams(WRAP, WRAP, Gravity.BOTTOM or Gravity.START))
        addView(block, LayoutParams(MATCH, MATCH).apply { setMargins(dp(56), dp(48), dp(56), dp(48)) })

        for (t in listOf(clock, date, caption)) t.setShadowLayer(dp(10).toFloat(), 0f, dp(1).toFloat(), 0xB3000000.toInt())
    }

    fun start() {
        stop()
        tick.run()
        main.postDelayed(shift, SHIFT_MS)
    }

    fun stop() {
        main.removeCallbacks(tick)
        main.removeCallbacks(shift)
    }

    fun setCaption(text: String?) {
        caption.animate().cancel()
        caption.animate().alpha(0f).setDuration(300).withEndAction {
            caption.text = text.orEmpty()
            if (text != null) caption.animate().alpha(1f).setDuration(700).start()
        }.start()
    }

    private fun updateClock() {
        val now = Date()
        val pattern = if (DateFormat.is24HourFormat(context)) "H:mm" else "h:mm"
        clock.text = SimpleDateFormat(pattern, Locale.getDefault()).format(now)
        date.text = SimpleDateFormat("EEEE d MMMM", Locale.getDefault()).format(now).uppercase(Locale.getDefault())
    }

    private fun moveBlock() {
        val r = dp(24)
        block.animate()
            .translationX((random.nextInt(2 * r + 1) - r).toFloat())
            .translationY(-random.nextInt(r + 1).toFloat())
            .setDuration(2000)
            .start()
    }

    private companion object {
        const val SHIFT_MS = 5 * 60_000L
    }
}
```

```kotlin file=app/src/main/kotlin/io/github/shalintripathi/canvas/frame/SlideshowView.kt
package io.github.shalintripathi.canvas.frame

import android.animation.Animator
import android.animation.ObjectAnimator
import android.animation.PropertyValuesHolder
import android.content.Context
import android.graphics.Bitmap
import android.graphics.Color
import android.graphics.PorterDuff
import android.os.Handler
import android.os.Looper
import android.os.SystemClock
import android.view.View
import android.view.ViewGroup
import android.view.animation.LinearInterpolator
import android.widget.FrameLayout
import android.widget.ImageView
import android.widget.LinearLayout
import io.github.shalintripathi.canvas.canvas
import io.github.shalintripathi.canvas.core.Captions
import io.github.shalintripathi.canvas.core.Slide
import io.github.shalintripathi.canvas.core.SlidePlanner
import io.github.shalintripathi.canvas.ui.MATCH
import io.github.shalintripathi.canvas.ui.dp
import java.util.concurrent.ExecutorService
import java.util.concurrent.Executors
import java.util.concurrent.RejectedExecutionException
import kotlin.random.Random

/**
 * The slide engine behind both the screensaver and the home wallpaper. Decodes off the main thread,
 * crossfades between slides, puts two portraits side by side, and optionally drifts each photo
 * (Ken Burns) under a clock-and-caption overlay.
 */
class SlideshowView(context: Context, private val config: Config) : FrameLayout(context) {

    data class Config(val holdMs: Long, val kenBurns: Boolean, val overlay: Boolean, val showClock: Boolean)

    /** Show only the built-in photos, even when the library has some. */
    var builtinOnly = false
        set(value) {
            if (field == value) return
            field = value
            reloadPhotos()
        }

    private class Decoded(val bitmaps: List<Bitmap>, val backdrop: Bitmap?, val duo: Boolean)

    private val app = context.canvas()
    private val planner = SlidePlanner()
    private val main = Handler(Looper.getMainLooper())
    private val decoder: ExecutorService = Executors.newSingleThreadExecutor()
    private val overlay: OverlayView? = if (config.overlay) OverlayView(context, config.showClock) else null
    private var front: FrameLayout? = null
    private var running = false
    private var generation = 0
    private var shownAt = 0L
    private val advance = Runnable { show(planner.next()) }
    private val onLibraryChanged: () -> Unit = { reloadPhotos() }

    init {
        setBackgroundColor(Color.BLACK)
        overlay?.let { addView(it, LayoutParams(MATCH, MATCH)) }
        reloadPhotos()
    }

    fun start() {
        if (running) return
        running = true
        app.library.addListener(onLibraryChanged)
        overlay?.start()
        if (front == null) show(planner.next()) else schedule(config.holdMs - (SystemClock.elapsedRealtime() - shownAt))
    }

    fun stop() {
        if (!running) return
        running = false
        main.removeCallbacks(advance)
        app.library.removeListener(onLibraryChanged)
        overlay?.stop()
    }

    fun release() {
        stop()
        decoder.shutdownNow()
        front?.let { removeLayer(it) }
        front = null
    }

    fun next() {
        if (!running) return
        main.removeCallbacks(advance)
        show(planner.next())
    }

    fun previous() {
        if (!running) return
        val slide = planner.previous() ?: return
        main.removeCallbacks(advance)
        show(slide)
    }

    private fun reloadPhotos() {
        val library = if (builtinOnly) emptyList() else app.library.all().map { it.toRef() }
        planner.setPhotos(library.ifEmpty { BitmapLoader.builtins(context) })
    }

    private fun schedule(delay: Long = config.holdMs) {
        main.removeCallbacks(advance)
        if (running) main.postDelayed(advance, delay.coerceAtLeast(1000))
    }

    private fun show(slide: Slide?) {
        if (slide == null) {
            schedule()
            return
        }
        val gen = ++generation
        val w = if (width > 0) width else resources.displayMetrics.widthPixels
        val h = if (height > 0) height else resources.displayMetrics.heightPixels
        try {
            decoder.execute {
                val decoded = decode(slide, w, h)
                main.post {
                    if (gen != generation || !running) return@post
                    if (decoded == null) {
                        schedule(2000)
                        return@post
                    }
                    crossfadeTo(layerFor(decoded), decoded.duo)
                    overlay?.setCaption(caption(slide))
                    shownAt = SystemClock.elapsedRealtime()
                    schedule()
                }
            }
        } catch (e: RejectedExecutionException) {
            // Released while a slide was pending.
        }
    }

    private fun caption(slide: Slide): String? {
        val takenAt = slide.photos.firstNotNullOfOrNull { app.library.get(it.id)?.takenAt }
        return Captions.forPhoto(takenAt, System.currentTimeMillis())
    }

    private fun decode(slide: Slide, w: Int, h: Int): Decoded? = try {
        when (slide) {
            is Slide.Single -> BitmapLoader.load(context, slide.photo.id, w, h)?.let { bitmap ->
                Decoded(listOf(bitmap), if (slide.photo.portrait) BitmapLoader.backdrop(bitmap) else null, duo = false)
            }
            is Slide.Duo -> {
                val left = BitmapLoader.load(context, slide.left.id, w / 2, h)
                val right = BitmapLoader.load(context, slide.right.id, w / 2, h)
                if (left == null || right == null) null else Decoded(listOf(left, right), null, duo = true)
            }
        }
    } catch (e: OutOfMemoryError) {
        null
    }

    private fun layerFor(d: Decoded): FrameLayout {
        val layer = FrameLayout(context)
        when {
            d.duo -> {
                val row = LinearLayout(context)
                d.bitmaps.forEachIndexed { i, bitmap ->
                    val params = LinearLayout.LayoutParams(0, MATCH, 1f)
                    if (i > 0) params.leftMargin = dp(6)
                    row.addView(image(bitmap, ImageView.ScaleType.CENTER_CROP), params)
                }
                layer.addView(row, LayoutParams(MATCH, MATCH))
            }
            d.backdrop != null -> {
                val back = image(d.backdrop, ImageView.ScaleType.CENTER_CROP)
                back.setColorFilter(0x8C000000.toInt(), PorterDuff.Mode.SRC_ATOP)
                layer.addView(back, LayoutParams(MATCH, MATCH))
                layer.addView(image(d.bitmaps[0], ImageView.ScaleType.FIT_CENTER), LayoutParams(MATCH, MATCH))
            }
            else -> layer.addView(image(d.bitmaps[0], ImageView.ScaleType.CENTER_CROP), LayoutParams(MATCH, MATCH))
        }
        return layer
    }

    private fun image(bitmap: Bitmap, scale: ImageView.ScaleType) = ImageView(context).apply {
        scaleType = scale
        setImageBitmap(bitmap)
    }

    private fun crossfadeTo(layer: FrameLayout, gentle: Boolean) {
        val old = front
        addView(layer, overlay?.let { indexOfChild(it) } ?: childCount, LayoutParams(MATCH, MATCH))
        front = layer
        layer.alpha = 0f
        layer.animate()
            .alpha(1f)
            .setDuration(if (old == null) FIRST_FADE_MS else FADE_MS)
            .withLayer()
            .withEndAction { if (old != null) removeLayer(old) }
            .start()
        if (config.kenBurns) startKenBurns(layer, gentle)
    }

    /** A slow zoom and drift that never shows the photo's edges. */
    private fun startKenBurns(layer: View, gentle: Boolean) {
        val zoom = if (gentle) 1.04f else KEN_BURNS_ZOOM
        val w = if (width > 0) width else resources.displayMetrics.widthPixels
        val h = if (height > 0) height else resources.displayMetrics.heightPixels
        val dx = (Random.nextFloat() - 0.5f) * w * (zoom - 1f)
        val dy = (Random.nextFloat() - 0.5f) * h * (zoom - 1f)
        val zoomIn = Random.nextBoolean()
        val animator = ObjectAnimator.ofPropertyValuesHolder(
            layer,
            PropertyValuesHolder.ofFloat(View.SCALE_X, if (zoomIn) 1f else zoom, if (zoomIn) zoom else 1f),
            PropertyValuesHolder.ofFloat(View.SCALE_Y, if (zoomIn) 1f else zoom, if (zoomIn) zoom else 1f),
            PropertyValuesHolder.ofFloat(View.TRANSLATION_X, if (zoomIn) 0f else dx, if (zoomIn) dx else 0f),
            PropertyValuesHolder.ofFloat(View.TRANSLATION_Y, if (zoomIn) 0f else dy, if (zoomIn) dy else 0f),
        )
        animator.duration = config.holdMs + 2 * FADE_MS
        animator.interpolator = LinearInterpolator()
        animator.start()
        layer.tag = animator
    }

    private fun removeLayer(layer: FrameLayout) {
        (layer.tag as? Animator)?.cancel()
        layer.animate().cancel()
        removeView(layer)
        clearImages(layer)
    }

    private fun clearImages(view: View) {
        when (view) {
            is ImageView -> view.setImageDrawable(null)
            is ViewGroup -> for (i in 0 until view.childCount) clearImages(view.getChildAt(i))
        }
    }

    private companion object {
        const val FADE_MS = 1500L
        const val FIRST_FADE_MS = 600L
        const val KEN_BURNS_ZOOM = 1.08f
    }
}
```

```kotlin file=app/src/main/kotlin/io/github/shalintripathi/canvas/frame/FrameDreamService.kt
/** The screensaver: Left and Right flip photos, volume keys pass through, anything else wakes the TV. */
class FrameDreamService : DreamService() {
    private var slideshow: SlideshowView? = null

    override fun onAttachedToWindow() {
        super.onAttachedToWindow()
        isInteractive = true
        isFullscreen = true
        isScreenBright = true
        val prefs = canvas().prefs
        val view = SlideshowView(
            this,
            SlideshowView.Config(holdMs = prefs.slideSeconds * 1000L, kenBurns = true, overlay = true, showClock = prefs.showClock),
        )
        slideshow = view
        setContentView(view)
    }

    override fun onDreamingStarted() {
        super.onDreamingStarted()
        slideshow?.start()
    }

    override fun onDreamingStopped() {
        slideshow?.stop()
        super.onDreamingStopped()
    }

    override fun onDetachedFromWindow() {
        slideshow?.release()
        slideshow = null
        super.onDetachedFromWindow()
    }

    override fun dispatchKeyEvent(event: KeyEvent): Boolean {
        when (event.keyCode) {
            KeyEvent.KEYCODE_DPAD_LEFT -> {
                if (event.action == KeyEvent.ACTION_DOWN) slideshow?.previous()
                return true
            }
            KeyEvent.KEYCODE_DPAD_RIGHT -> {
                if (event.action == KeyEvent.ACTION_DOWN) slideshow?.next()
                return true
            }
            KeyEvent.KEYCODE_VOLUME_UP, KeyEvent.KEYCODE_VOLUME_DOWN, KeyEvent.KEYCODE_VOLUME_MUTE ->
                return super.dispatchKeyEvent(event)
        }
        finish()
        return true
    }
}
```

```kotlin file=app/src/main/kotlin/io/github/shalintripathi/canvas/phone/ApiRouter.kt
package io.github.shalintripathi.canvas.phone

import io.github.shalintripathi.canvas.CanvasApp
import io.github.shalintripathi.canvas.core.HomeLayout
import io.github.shalintripathi.canvas.core.LibraryJson
import io.github.shalintripathi.canvas.core.Pairing
import io.github.shalintripathi.canvas.core.http.HttpHandler
import io.github.shalintripathi.canvas.core.http.HttpRequest
import io.github.shalintripathi.canvas.core.http.HttpResponse
import io.github.shalintripathi.canvas.library.PhotoLibrary
import io.github.shalintripathi.canvas.settings.Prefs
import org.json.JSONArray
import org.json.JSONException
import org.json.JSONObject
import java.io.IOException

/**
 * The phone page's HTTP API. Everything under /api/ needs a paired phone's cookie; anything that
 * changes state also needs the X-Canvas header, which a cross-site page cannot send without CORS.
 */
class ApiRouter(private val app: CanvasApp, private val pairing: Pairing) : HttpHandler {

    override fun handle(request: HttpRequest): HttpResponse {
        val path = request.path
        val method = request.method
        if (method == "GET" && (path == "/" || path == "/index.html")) return page()
        if (method == "GET" && path == "/pair") return pairWithToken(request)
        if (!path.startsWith("/api/")) return HttpResponse.error(404, "Not found")
        if (method != "GET" && request.header("x-canvas") != "1") return HttpResponse.error(403, "Missing X-Canvas header")
        if (method == "POST" && path == "/api/pair") return pairWithPin(request)

        val session = request.cookies[COOKIE]
        if (!pairing.isPaired(session)) return HttpResponse.error(401, "Not paired")
        val seg = path.removePrefix("/api/").split('/')
        return when {
            seg == listOf("photos") && method == "GET" -> listPhotos()
            seg == listOf("photos") && method == "PUT" -> upload(request)
            seg.size == 2 && seg[0] == "photos" && method == "DELETE" -> deletePhoto(seg[1])
            seg.size == 3 && seg[0] == "photos" && seg[2] == "thumb" && method == "GET" -> thumb(seg[1])
            seg.size == 3 && seg[0] == "photos" && seg[2] == "favorite" && method == "PUT" -> favorite(seg[1], request)
            seg == listOf("settings") && method == "GET" -> settings()
            seg == listOf("settings") && method == "PUT" -> updateSettings(request)
            seg == listOf("apps") && method == "GET" -> apps()
            seg.size == 3 && seg[0] == "apps" && seg[2] == "icon" && method == "GET" -> icon(seg[1])
            seg == listOf("home") && method == "PUT" -> updateHome(request)
            seg == listOf("phones") && method == "GET" -> phones(session)
            seg.size == 2 && seg[0] == "phones" && method == "DELETE" -> revokePhone(seg[1])
            else -> HttpResponse.error(404, "Not found")
        }
    }

    private fun page(): HttpResponse =
        HttpResponse.bytes(app.assets.open("web/index.html").use { it.readBytes() }, "text/html; charset=utf-8")

    private fun pairWithToken(r: HttpRequest): HttpResponse {
        val session = pairing.pairWithToken(r.query["t"].orEmpty(), Pairing.deviceLabel(r.header("user-agent")))
            ?: return HttpResponse.redirect("/?expired=1")
        return HttpResponse.redirect("/", mapOf("Set-Cookie" to cookie(session)))
    }

    private fun pairWithPin(r: HttpRequest): HttpResponse {
        val body = json(r) ?: return HttpResponse.error(400, "Bad JSON")
        val pin = body.optString("pin").filter { it.isDigit() }
        return when (val result = pairing.pairWithPin(pin, Pairing.deviceLabel(r.header("user-agent")))) {
            is Pairing.PinResult.Paired -> HttpResponse.json(OK, headers = mapOf("Set-Cookie" to cookie(result.session)))
            is Pairing.PinResult.Wrong -> HttpResponse.error(403, "Wrong code. ${result.attemptsLeft} tries left.")
            Pairing.PinResult.NoCode -> HttpResponse.error(410, "No active code. On the TV, open Phone to get a new one.")
        }
    }

    private fun listPhotos(): HttpResponse {
        val array = JSONArray()
        app.library.all().sortedByDescending { it.addedAt }.forEach { array.put(LibraryJson.toJson(it)) }
        return HttpResponse.json(array.toString())
    }

    private fun upload(r: HttpRequest): HttpResponse {
        if (r.contentLength <= 0) return HttpResponse.error(400, "Empty upload")
        return try {
            val entry = app.library.add(r.body, r.contentLength, r.query["takenAt"]?.toLongOrNull())
            HttpResponse.json(LibraryJson.toJson(entry).toString(), 201)
        } catch (e: PhotoLibrary.UnsupportedImageException) {
            HttpResponse.error(415, e.message ?: "Unsupported image")
        } catch (e: IOException) {
            HttpResponse.error(400, "Upload interrupted")
        }
    }

    private fun deletePhoto(id: String) =
        if (app.library.delete(id)) HttpResponse.json(OK) else HttpResponse.error(404, "No such photo")

    private fun thumb(id: String): HttpResponse {
        if (app.library.get(id) == null) return HttpResponse.error(404, "No such photo")
        val file = app.library.thumbFile(id)
        return if (file.exists()) HttpResponse.file(file, "image/jpeg", CACHE) else HttpResponse.error(404, "No such photo")
    }

    private fun favorite(id: String, r: HttpRequest): HttpResponse {
        val body = json(r) ?: return HttpResponse.error(400, "Bad JSON")
        return if (app.library.setFavorite(id, body.optBoolean("favorite"))) HttpResponse.json(OK)
        else HttpResponse.error(404, "No such photo")
    }

    private fun settings(): HttpResponse {
        val system = app.system
        val prefs = app.prefs
        val screensaver = JSONObject()
            .put("useCanvas", prefs.useCanvasScreensaver)
            .put("active", system.isCanvasScreensaver() ?: prefs.useCanvasScreensaver)
            .put("canChange", system.canChange())
            .put("startAfterMin", system.startAfterMinutes())
            .put("turnOffAfterMin", system.turnOffAfterMinutes(prefs))
            .put("slideSeconds", prefs.slideSeconds)
            .put("showClock", prefs.showClock)
        val home = JSONObject().put("wallpaper", prefs.wallpaper)
        return HttpResponse.json(JSONObject().put("screensaver", screensaver).put("home", home).toString())
    }

    private fun updateSettings(r: HttpRequest): HttpResponse {
        val body = json(r) ?: return HttpResponse.error(400, "Bad JSON")
        val system = app.system
        val prefs = app.prefs
        val s = body.optJSONObject("screensaver")
        if (s != null) {
            if (s.has("useCanvas")) {
                val on = s.optBoolean("useCanvas")
                prefs.useCanvasScreensaver = on
                val applied = if (on) system.useCanvas() else system.restorePrevious(prefs)
                if (!applied) return HttpResponse.error(409, "The TV didn't allow this change. Run tools/canvas install again.")
            }
            if (s.has("startAfterMin")) {
                val minutes = s.optInt("startAfterMin")
                if (minutes !in START_AFTER) return HttpResponse.error(400, "Pick 5, 10, 15 or 30 minutes")
                if (!system.setStartAfterMinutes(minutes)) return HttpResponse.error(409, "The TV didn't allow this change.")
            }
            if (s.has("turnOffAfterMin")) {
                val minutes = s.optInt("turnOffAfterMin")
                if (minutes !in TURN_OFF) return HttpResponse.error(400, "Pick 15, 30, 60 or 240 minutes, or never")
                if (!system.setTurnOffAfterMinutes(minutes, prefs)) return HttpResponse.error(409, "The TV didn't allow this change.")
            }
            if (s.has("slideSeconds")) prefs.slideSeconds = s.optInt("slideSeconds")
            if (s.has("showClock")) prefs.showClock = s.optBoolean("showClock")
        }
        val wallpaper = body.optJSONObject("home")?.optString("wallpaper").orEmpty()
        if (wallpaper == Prefs.WALLPAPER_PHOTOS || wallpaper == Prefs.WALLPAPER_BUILTIN) prefs.wallpaper = wallpaper
        return settings()
    }

    private fun apps(): HttpResponse {
        val repo = app.apps
        val labels = repo.labels(repo.excludedPackages())
        val layout = app.prefs.layout(labels.map { it.first })
        val array = JSONArray()
        for ((pkg, label) in labels) {
            array.put(
                JSONObject().put("pkg", pkg).put("label", label)
                    .put("dock", layout.dock.indexOf(pkg)).put("hidden", pkg in layout.hidden),
            )
        }
        return HttpResponse.json(array.toString())
    }

    private fun icon(pkg: String): HttpResponse {
        val png = app.apps.artPng(pkg) ?: return HttpResponse.error(404, "No such app")
        return HttpResponse.bytes(png, "image/png", CACHE)
    }

    private fun updateHome(r: HttpRequest): HttpResponse {
        val body = json(r) ?: return HttpResponse.error(400, "Bad JSON")
        val dock = strings(body.optJSONArray("dock")).distinct().take(HomeLayout.MAX_DOCK)
        val hidden = strings(body.optJSONArray("hidden")).toSet()
        app.prefs.saveLayout(HomeLayout(dock, hidden))
        return apps()
    }

    private fun phones(session: String?): HttpResponse {
        val mine = pairing.phoneFor(session)?.id
        val array = JSONArray()
        pairing.phones().sortedByDescending { it.pairedAt }.forEach {
            array.put(JSONObject().put("id", it.id).put("label", it.label).put("pairedAt", it.pairedAt).put("current", it.id == mine))
        }
        return HttpResponse.json(array.toString())
    }

    private fun revokePhone(id: String) =
        if (pairing.revoke(id)) HttpResponse.json(OK) else HttpResponse.error(404, "No such phone")

    private fun json(r: HttpRequest): JSONObject? = try {
        JSONObject(r.bodyText())
    } catch (e: JSONException) {
        null
    }

    private fun strings(array: JSONArray?): List<String> =
        if (array == null) emptyList() else (0 until array.length()).mapNotNull { array.optString(it).takeIf { s -> s.isNotBlank() } }

    companion object {
        const val COOKIE = "canvas_session"
        private const val OK = "{\"ok\":true}"
        private val CACHE = mapOf("Cache-Control" to "private, max-age=86400")
        private val START_AFTER = setOf(5, 10, 15, 30)
        private val TURN_OFF = setOf(15, 30, 60, 240, -1)

        fun cookie(session: String) = "$COOKIE=$session; Path=/; Max-Age=31536000; HttpOnly; SameSite=Lax"
    }
}
```

```kotlin file=app/src/main/kotlin/io/github/shalintripathi/canvas/phone/Qr.kt
package io.github.shalintripathi.canvas.phone

import android.graphics.Bitmap
import android.graphics.Color
import com.google.zxing.BarcodeFormat
import com.google.zxing.EncodeHintType
import com.google.zxing.qrcode.QRCodeWriter

object Qr {
    fun encode(text: String, size: Int): Bitmap {
        val matrix = QRCodeWriter().encode(text, BarcodeFormat.QR_CODE, size, size, mapOf(EncodeHintType.MARGIN to 1))
        val w = matrix.width
        val pixels = IntArray(w * matrix.height) { i -> if (matrix.get(i % w, i / w)) Color.BLACK else Color.WHITE }
        return Bitmap.createBitmap(pixels, w, matrix.height, Bitmap.Config.RGB_565)
    }
}
```

```html file=app/src/main/assets/web/index.html
async function api(method, path, body) {

function upload(file, i, n) {
  return new Promise((resolve, reject) => {
    if (file.size > MAX_UPLOAD) { reject(new Error(file.name + " is over 40 MB")); return; }
    const xhr = new XMLHttpRequest();
    xhr.open("PUT", "/api/photos?name=" + encodeURIComponent(file.name) + "&takenAt=" + (file.lastModified || 0));
    xhr.setRequestHeader("X-Canvas", "1");
    xhr.setRequestHeader("Content-Type", file.type || "application/octet-stream");
    xhr.upload.onprogress = (e) => {
      if (!e.lengthComputable) return;
      $("progBar").style.width = Math.round(((i + e.loaded / e.total) / n) * 100) + "%";
      $("progText").textContent = "Uploading " + (i + 1) + " of " + n + "…";
    };
    xhr.onload = () => {
      if (xhr.status === 201) { resolve(); return; }
      if (xhr.status === 401) { showPair(); reject(new Error("Not paired")); return; }
      let message = "Upload failed (" + xhr.status + ")";
      try { message = JSON.parse(xhr.responseText).error || message; } catch (_) { /* not JSON */ }
      reject(new Error(message));
    };
    xhr.onerror = () => reject(new Error("Network error. Is your phone on the same Wi-Fi as the TV?"));
    xhr.send(file);
  });
}
```

```kotlin file=app/src/main/kotlin/io/github/shalintripathi/canvas/home/PopupList.kt
/** A small D-pad menu shown under (or above) a view. */
object PopupList {
    class Item(val label: String, val action: () -> Unit)

    fun show(anchor: View, items: List<Item>, width: Int, onDismiss: () -> Unit): PopupWindow {
        val context = anchor.context
        val list = LinearLayout(context)
        list.orientation = LinearLayout.VERTICAL
        list.setPadding(context.dp(8), context.dp(8), context.dp(8), context.dp(8))
        list.background = roundRect(0xF02A2A2E.toInt(), context.dp(16).toFloat(), context.dp(1), 0x26FFFFFF)

        val popup = PopupWindow(list, width, WRAP, true)
        val rows = items.map { item ->
            row(context, item.label).apply {
                setOnClickListener {
                    popup.dismiss()
                    item.action()
                }
            }
        }
        rows.forEach { list.addView(it, LinearLayout.LayoutParams(MATCH, context.dp(36))) }
        rows.forEachIndexed { i, r ->
            r.nextFocusUpId = rows[maxOf(0, i - 1)].id
            r.nextFocusDownId = rows[minOf(rows.lastIndex, i + 1)].id
            r.nextFocusLeftId = r.id
            r.nextFocusRightId = r.id
        }
        popup.isOutsideTouchable = true
        popup.elevation = context.dp(16).toFloat()
        popup.setOnDismissListener { onDismiss() }
        popup.showAsDropDown(anchor, 0, context.dp(8), Gravity.START)
        rows.firstOrNull()?.requestFocus()
        return popup
    }

    private fun row(context: Context, label: String): TextView {
        val background = roundRect(Color.TRANSPARENT, context.dp(10).toFloat())
        return context.text(13f, "sans-serif", Color.WHITE).apply {
            text = label
            id = View.generateViewId()
            gravity = Gravity.CENTER_VERTICAL
            setPadding(context.dp(14), 0, context.dp(14), 0)
            isFocusable = true
            this.background = background
            setOnFocusChangeListener { _, has ->
                background.setColor(if (has) 0xF2FFFFFF.toInt() else Color.TRANSPARENT)
                setTextColor(if (has) 0xFF111111.toInt() else Color.WHITE)
            }
        }
    }
}
```

```kotlin file=app/src/main/kotlin/io/github/shalintripathi/canvas/home/Inputs.kt
package io.github.shalintripathi.canvas.home

import android.app.Activity
import android.content.Context
import android.content.Intent
import android.media.tv.TvContract
import android.media.tv.TvInputInfo
import android.media.tv.TvInputManager
import android.provider.Settings
import io.github.shalintripathi.canvas.apps.AppRepository
import io.github.shalintripathi.canvas.ui.launch

/** Entries for the Inputs menu: HDMI and AV inputs, then the TV's Live TV app. */
object Inputs {
    fun items(activity: Activity, repo: AppRepository): List<PopupList.Item> {
        val items = ArrayList<PopupList.Item>()
        val liveTv = repo.liveTvPackage()
        val openLiveTv = { liveTv?.let { repo.launchIntent(it) }?.let { activity.launch(it) } }
        val inputs = try {
            val manager = activity.getSystemService(Context.TV_INPUT_SERVICE) as? TvInputManager
            manager?.tvInputList.orEmpty().filter { it.isPassthroughInput && !it.isHidden(activity) }
        } catch (e: RuntimeException) {
            emptyList()
        }
        for (info in inputs.sortedBy { label(activity, it).lowercase() }) {
            items += PopupList.Item(label(activity, info)) {
                val intent = Intent(Intent.ACTION_VIEW, TvContract.buildChannelUriForPassthroughInput(info.id))
                if (!activity.launch(intent)) openLiveTv()
            }
        }
        if (liveTv != null) items += PopupList.Item("Live TV") { openLiveTv() }
        if (items.isEmpty()) items += PopupList.Item("Settings") { activity.launch(Intent(Settings.ACTION_SETTINGS)) }
        return items
    }

    private fun label(context: Context, info: TvInputInfo): String {
        val custom = info.loadCustomLabel(context)
        return (if (custom.isNullOrEmpty()) info.loadLabel(context) else custom).toString()
    }
}
```

```kotlin file=app/src/main/kotlin/io/github/shalintripathi/canvas/home/HomeActivity.kt
    private fun onTileFocused(info: AppInfo, inDock: Boolean, box: View) {
        lastFocusedPkg = info.pkg

    private fun restoreFocus() {
        val tile = (dockCards + gridCards).firstOrNull { (it.tag as AppInfo).pkg == lastFocusedPkg }
        val pill = header.pills.firstOrNull { it.id == lastFocusedPill }
        (tile ?: pill ?: dockCards.firstOrNull() ?: gridCards.firstOrNull() ?: header.pills.first()).requestFocus()
    }

    /** Explicit D-pad targets: one row per press, no wrapping at the ends of rows or the pill bar. */
    private fun wireFocus() {
        val pills = header.pills
        val d = dockCards.size
        val g = gridCards.size
        val belowPills = dockCards.getOrNull(minOf(d - 1, d / 2)) ?: gridCards.firstOrNull()
        for ((i, p) in pills.withIndex()) {
            p.nextFocusLeftId = (if (i == 0) p else pills[i - 1]).id
            p.nextFocusRightId = (if (i == pills.lastIndex) p else pills[i + 1]).id
            p.nextFocusUpId = p.id
            p.nextFocusDownId = (belowPills ?: p).id
        }
        val topId = pills.first().id
        for ((i, c) in dockCards.withIndex()) {
            c.nextFocusUpId = topId
            c.nextFocusLeftId = (if (i == 0) c else dockCards[i - 1]).id
            c.nextFocusRightId = (if (i == d - 1) c else dockCards[i + 1]).id
            c.nextFocusDownId = (if (g > 0) gridCards[minOf(i, g - 1)] else c).id
        }
        val lastRow = (g - 1) / COLUMNS
        for ((j, c) in gridCards.withIndex()) {
            val r = j / COLUMNS
            val col = j % COLUMNS
            c.nextFocusUpId = when {
                r > 0 -> gridCards[j - COLUMNS].id
                d > 0 -> dockCards[minOf(col, d - 1)].id
                else -> topId
            }
            c.nextFocusDownId = when {
                j + COLUMNS < g -> gridCards[j + COLUMNS].id
                r < lastRow -> gridCards[g - 1].id
                else -> c.id
            }
            c.nextFocusLeftId = (if (col == 0) c else gridCards[j - 1]).id
            c.nextFocusRightId = (if (col == COLUMNS - 1 || j == g - 1) c else gridCards[j + 1]).id
        }
    }

    private fun scrollToRow(tileBox: View) {
        val row = tileBox.parent as View
        val screenHeight = resources.displayMetrics.heightPixels
        // First grid row: slide the dock band up to the top edge. Later rows sit a little above centre.
        val band = dockRow.parent as View
        val target = if (grid.indexOfChild(row) == 0) {
            hero.top + band.top + dockRow.top - dp(22)
        } else {
            grid.top + row.top - (screenHeight * 0.42f).toInt()
        }
        val max = maxOf(0, content.height - scroll.height)
        scroll.smoothScrollTo(0, target.coerceIn(0, max))
    }

    private fun showTileMenu(anchor: View, info: AppInfo, inDock: Boolean) {
        val items = ArrayList<PopupList.Item>()
        if (inDock) {
            val i = layout.dock.indexOf(info.pkg)
            if (i > 0) items += PopupList.Item("Move left") { app.prefs.saveLayout(layout.moveLeft(info.pkg)) }
            if (i in 0 until layout.dock.lastIndex) items += PopupList.Item("Move right") { app.prefs.saveLayout(layout.moveRight(info.pkg)) }
            items += PopupList.Item("Remove from dock") { app.prefs.saveLayout(layout.removeFromDock(info.pkg)) }
        } else if (layout.dock.size < HomeLayout.MAX_DOCK) {
            items += PopupList.Item("Add to dock") { app.prefs.saveLayout(layout.addToDock(info.pkg)) }
        }
        items += PopupList.Item("Hide") {
            lastFocusedPkg = null
            app.prefs.saveLayout(layout.hide(info.pkg))
        }
        items += PopupList.Item("App info") {
            launch(Intent(Settings.ACTION_APPLICATION_DETAILS_SETTINGS, Uri.parse("package:" + info.pkg)))
        }
        popup?.dismiss()
        popup = PopupList.show(anchor, items, dp(200)) {
            popup = null
            restoreFocus()
        }
    }

    // ---------------------------------------------------------------- glow

    private fun setGlow(color: Int) {
        glowColor = color
        val g = GradientDrawable()
        g.setGradientType(GradientDrawable.RADIAL_GRADIENT)
        g.setGradientCenter(0.5f, 0.78f)
        g.setGradientRadius(resources.displayMetrics.widthPixels * 0.62f)
        g.setColors(intArrayOf(withAlpha(color, 0.5f), withAlpha(color, 0.14f), Color.TRANSPARENT))
        glow.background = g
    }

    private fun animateGlow(to: Int) {
        glowAnim?.cancel()
        val animator = ValueAnimator.ofObject(ArgbEvaluator(), glowColor, to)
        animator.duration = 450
        animator.addUpdateListener { setGlow(it.animatedValue as Int) }
        animator.start()
        glowAnim = animator
    }

    private fun fadeGlow(alpha: Float) {
        glow.animate().alpha(alpha).setDuration(300).start()
        // The grid sits over the photo's busiest part, so dim the photo while browsing apps.
        gridShade.animate().alpha(if (alpha < 1f) 1f else 0f).setDuration(300).start()
    }

    // ---------------------------------------------------------------- entrance

    private fun playEntrance() {
        val top = header.view
        top.alpha = 0f
        top.translationY = -dp(12).toFloat()
        top.animate().alpha(1f).translationY(0f).setDuration(500).setStartDelay(80).start()
        title.alpha = 0f
        title.animate().alpha(1f).setDuration(500).setStartDelay(200).start()
        for (i in 0 until dockRow.childCount) {
            val t = dockRow.getChildAt(i)
            t.alpha = 0f
            t.translationY = dp(24).toFloat()
            t.animate().alpha(1f).translationY(0f).setInterpolator(DecelerateInterpolator(2f))
                .setDuration(450).setStartDelay(160 + i * 60L).start()
        }
    }

    private companion object {
        const val COLUMNS = 5
        const val WALLPAPER_MS = 10 * 60_000L
    }
}
```

````markdown file=README.md
# Canvas: a fast, ad-free home screen and photo frame for Android TV and Google TV

**Canvas replaces the slow, ad-filled Google TV home screen with a clean, fast one, and turns your TV into a photo frame when nobody is watching.** Add photos from your phone over Wi-Fi (on Android that includes Google Photos). ## What you get

- **A fast home screen.** A dock of your favourite apps, every other app one press below, a clock, and your Inputs (HDMI, Live TV) one click away. No ads, no "sponsored" rows, no autoplaying trailers. Opens in {start_ms} ms and uses {pss_mb} MB on a 2 GB Sony BRAVIA (Google's own launcher uses 88 MB while idle).
- **A photo-frame screensaver.** Your photos with a slow pan and zoom, soft crossfades, two portrait photos side by side, and a caption like "March 2023 · 3 years ago". Left and Right on the remote flip photos. It never starts while a video is playing.

## Install

You need a computer on the same Wi-Fi as the TV (macOS, Linux or Windows with Python 3).

## FAQ

**How do I remove ads from the Google TV home screen?**
Google TV's home screen (`com.google.android.apps.tv.launcherx`) is where the ads and sponsored rows live. Canvas replaces it: `tools/canvas install` disables the stock launcher (reversibly) and makes Canvas the Home app. Your apps, the Play Store and the remote's voice button keep working.

**Can Android TV show my Google Photos as a screensaver?**
Yes. Google stopped letting outside apps sync your Google Photos albums in March 2025, so Canvas takes the photos straight from your phone instead: on Android, the photo picker that opens from the Canvas phone page includes Google Photos. The photos are copied to the TV and shown by the Canvas screensaver. If you want albums that update by themselves, keep Google's Ambient mode (`tools/canvas restore`).

**Can I use my TV as free digital signage for my shop or clinic?**
That is Canvas's next milestone: offers, menus, QR codes (UPI, Google reviews), a clinic token display and business hours, managed from your phone, on the TV you already own, without a player box or a monthly fee. Watch or star the repo to follow it.

**Is it safe? Does it send my photos anywhere?**
No. Canvas has no account and no cloud. The phone page is served by the TV itself on your home network, phones must pair with a code shown on the TV, and photos are stored only on the TV.

**Which TVs work?**
Android TV and Google TV running Android 7.0 or newer: Sony BRAVIA, TCL, Xiaomi/Redmi, OnePlus, Hisense and Philips Android models, Nvidia Shield, Chromecast with Google TV, Google TV Streamer, Mi Box. Not Samsung (Tizen), LG (webOS), Roku or VIDAA TVs. Amazon Fire TV runs the app but blocks replacing the home screen and screensaver.
````
